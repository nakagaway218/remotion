# Learner スマホ版 使い方

高校生向け学習QAを、スマホで ChatGPT / Claude / Gemini に貼り付けて使いやすくするためのHTMLツールです。

## 開くファイル

スマホでは、次のファイルをブラウザーで開いてください。

```text
C_Learner_Mobile.html
```

Windows用の `.cmd` ファイルはスマホでは使いません。

## 基本の流れ

1. 使うAIを選びます。
2. 科目を選びます。
3. 質問を直接入力、または画像読み取りを選びます。
4. 質問文を入力します。
5. `質問文を作成` を押します。
6. 作成された文面をコピーして、選んだAIのチャット画面に貼り付けます。
7. AIの回答をこのツールに貼り戻します。
8. 必要に応じて、別解や詳しい解説などを追加で依頼します。
9. 終わるときは `[終了]` を押します。

## 音声入力

スマホのブラウザーやOSによっては、HTML内の音声入力ボタンが使えない場合があります。

その場合は、スマホ標準キーボードのマイク入力を使って質問欄へ入力してください。

## 注意

- zipを展開してから使ってください。
- うまく開けない場合は、Chromeで試してください。
- ChatGPT / Claude / Gemini のアプリではなく、ブラウザー版を使う方がコピー貼り付けしやすい場合があります。
- API連携は通常利用では不要です。
