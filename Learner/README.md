# Learner

高校生向け学習QAを、ChatGPT / Claude / Gemini に貼り付けて使いやすくするためのローカルHTMLツールです。

## 起動

通常はこのファイルをダブルクリックします。

```powershell
C_Learner_Start.cmd
```

ブラウザーで `C_Learner_Index.html` が開きます。

## 通常の使い方

1. 使用するAIを選びます。
2. 科目を選びます。
3. 質問を直接入力、または画像読み取りを選びます。
4. 質問文を入力します。
5. `質問文を作成` を押します。
6. `コピーしてAIを開く` または `コピー` を使って、AI画面へ貼り付けます。
7. AIの回答を `AIから返ってきた回答` 欄へ貼り付けます。
8. Step4の追加オプションを選びます。
9. 続ける場合は次の質問へ進み、終わる場合は `[終了]` を押します。

## 音声入力

質問欄では `音声入力を開始` が使えます。

- Google Chromeでの利用を想定しています。
- 初回はマイク許可が必要です。
- ブラウザーや設定によって使えない場合があります。

## Step4追加オプション

追加オプションは、すでに開いている同じAIチャットへ貼り付ける想定です。

そのため、Step4の追加依頼では `コピーしてAIを開く` は表示せず、`コピー` だけ使います。

## API連携

API連携は将来用・補助用です。

OpenAI APIを使う場合は、環境変数 `OPENAI_API_KEY` を設定してからサーバー起動用の `01_START_LEARNER.cmd` を使います。

APIキーはHTMLには保存しません。

## 現在入れていない機能

参考資料をHTMLから直接開く機能は削除しています。

Windows環境でExcelやPowerPointの直接起動が不安定になり、ツール全体の安定性を下げたためです。今後この機能を戻す場合は、入口を増やしすぎない形で慎重に設計してください。

## 保守用メモ

このフォルダーには、次回以降のCodexやサブエージェントが迷わないように以下を置いています。

変更前にこれらを確認してください。
