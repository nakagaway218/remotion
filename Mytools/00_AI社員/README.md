# Mytools AI社員

Windows ツール改善に使う AI 社員の一覧です。

| AI 社員 | 呼び出しの目安 | 成果物 |
| --- | --- | --- |
| ツール要件整理担当 | 何を直すか曖昧なとき | `requirements.md` |
| 既存コード調査担当 | `.bat` や `.py` の現状を見るとき | `research.md` |
| 改善手順設計担当 | 変更手順を分けたいとき | `plan.md` |
| ツール実装担当 | コードや README を直すとき | 修正済みファイル |
| 動作確認担当 | 実行やテスト観点を確認するとき | `test.md` |
| README・手順整形担当 | 使い方や exe 化手順を整えるとき | README 更新 |
| 変更記録係 | 次回再開用にまとめるとき | `handoff.md` |

## 使い方

まず `../WORKFORCE_SPEC.md` を埋めます。

小さい修正では、必要な担当だけ使います。実装を伴う変更では、`AI_WORKFORCE.md` の標準フローに沿って進めます。
