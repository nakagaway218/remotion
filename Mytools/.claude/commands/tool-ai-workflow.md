# /tool-ai-workflow [改善したい内容]

`AI_WORKFORCE.md` と `WORKFORCE_SPEC.md` を読み、`[改善したい内容]` を Mytools の AI 社員フローに分解してください。

## 手順

1. ツール要件整理担当として、困っている動作、対象ツール、完成条件を整理する。
2. 既存コード調査担当として、読むべき `.bat`、`.py`、README、設定を列挙する。
3. 改善手順設計担当として、変更手順、影響範囲、テスト観点を分ける。
4. ツール実装担当として、修正すべきファイルと変更内容を整理する。
5. 動作確認担当として、Windows で確認すべき起動、変換、出力、エラー処理を挙げる。
6. README・手順整形担当として、ユーザー向け説明や exe 化手順の更新点を決める。
7. 変更記録係として、保存先と引き継ぎファイルを提案する。

```markdown

### 使うAI社員

### ユーザー確認ポイント

### 自動で進めてよい範囲

### 次の一手
```

実ファイルの削除、移動、上書き、`.exe` の GitHub 追加は、明示的な確認がある場合だけ提案してください。
