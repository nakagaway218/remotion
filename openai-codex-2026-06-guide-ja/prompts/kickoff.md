# キックオフ・プロンプト（コピペ用）

このリポジトリを AI エージェント（Codex など）に渡したあと、最初に貼り付ける文です。
そのままコピーして使えます。`{ }` の部分だけ、分かる範囲で書き換えてください（分からなければ空欄のままでOK）。

---

## そのまま貼り付ける用（基本）

```
このリポジトリの AGENTS.md を読んで、その手順どおりに進めてください。
わたしはコードがほとんど分かりません。日常語で、ひとつずつ確認しながら進めてください。

まずは AGENTS.md の STEP 1（インタビュー）から始めて、
「どんな iOS アプリを作りたいか」を質問で引き出してください。
一度にたくさん聞かず、1〜3問ずつでお願いします。
```

## アイデアが既にある場合（任意で追記）

上の文の後ろに、分かる範囲でこれを足すと早く進みます。

```
ちなみに今のところのイメージ:
- 作りたいもの: { 例: 毎日の習慣を記録するアプリ }
- 使う人: { 例: 自分ひとり / 家族 }
- やりたいこと: { 例: 習慣を登録して、できた日にチェックする }
- 残したいデータ: { 例: 習慣の名前と、できた日付 }
- 見た目の雰囲気: { 例: シンプルで明るい色 }
- アプリ名（仮）: { 例: まいにち }
```

## 環境がまだ整っていない場合

```
まだ Xcode を入れていない / Codex の Build iOS Apps プラグインを入れていません。
必要な準備を、順番に1つずつ案内してください。準備が終わるまで設計の相談だけ進めてもOKです。
```
