# まずはここから（START HERE）

このリポジトリは、**AI エージェントと対話しながら iOS アプリを作っていく**ためのスターターキットです。
コードが分からなくても大丈夫。AI が質問してくれるので、答えていくだけで進みます。

---

## 3ステップで始める

### STEP 1. AI エージェントを用意する
- おすすめは **OpenAI Codex**（iOS を作るなら **Build iOS Apps プラグイン**も入れる → `docs/03-build-ios-apps.md`）。
- Claude などでもOK（その場合は「AGENTS.md を読んで進めて」と伝えてください）。
- iOS を実際にビルドするには **Mac ＋ Xcode** が必要です（無くても設計の相談までは進められます）。

### STEP 2. このリポジトリを AI に渡す
- Codex / IDE でこのフォルダを開く、または:

```bash
git clone https://github.com/fuuuuuuma/openai-codex-2026-06-guide-ja.git
cd openai-codex-2026-06-guide-ja
```

### STEP 3. キックオフ文を貼る
- `prompts/kickoff.md` の文をコピーして、AI に貼り付けるだけ。
- いちばん短い版はこれです:

```
このリポジトリの AGENTS.md を読んで、その手順どおりに進めてください。
わたしはコードがほとんど分かりません。日常語で、ひとつずつ確認しながら進めてください。
まずは STEP 1（インタビュー）から、どんな iOS アプリを作りたいか質問してください。
```

これで AI が「どんなアプリ？」「誰のため？」と聞いてくれます。答えていくと、`app/` の中にアプリが育っていきます。

---

## 困ったら

- 何から話せばいいか分からない → そのまま「何から決めればいい？」と AI に聞けばOK。
- 専門用語が出てきた → 「それ、もっとやさしく説明して」と言えばOK。
- 今どこまで決まったか知りたい → 「今の仕様を見せて」と言うと `app/SPEC.md` を見せてくれます。

> このキットの背景にある OpenAI の最新アップデート（ChatGPT の新メモリ、Codex プロフィール、iOS ビルド）は `README.md` と `docs/` にまとめています。
