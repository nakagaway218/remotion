# Studymaterials

中学生向け教材・学習管理資料を置くフォルダ。

このフォルダでは、Excel / PowerPoint / Markdown の教材を、印刷してそのまま使える形で保管する。新しく編集するときは、まず `AI_CONTEXT.md` と `SKILL.md` を確認する。

## 主要ファイル

### 英作文教材

- `中学生英作文be動詞現在形編.xlsx`
  - 中学生向け英作文教材。
  - 問題と解答の対応、行高、A4縦印刷、改頁位置を崩さないことを優先する。

- `中学生英作文一般動詞現在形編.xlsx`
  - `中学生英作文be動詞現在形編.xlsx` から派生させた一般動詞現在形の英作文教材。
  - 基本文は `私はテニスをします。`。主語を変え、`play / plays`、`do / does`、`do not / don't`、`does not / doesn't` を練習する。
  - 派生時は、内容だけでなく改頁、太い横罫線、注釈行の斜体、印刷の上下中央寄せを必ず再確認する。
  - 改頁は見出し行そのものではなく、次ページ開始見出しの1行前に入れる。

### 生活記録・計画表

- `生活記録表生徒用_縦型.xlsx`
  - 生徒用の生活記録表。
  - `縦型日曜始まり` は日曜始まり、`縦型月曜始まり` は月曜始まり。
  - タイトルは `生活記録表（縦型）`。
  - A4縦1枚、左右同余白、水平中央寄せで印刷する。

- `生活記録表生徒用_横型.xlsx`
  - 生徒用の生活記録表のA4横版。
  - `横型日曜始まり` は日曜始まり、`横型月曜始まり` は月曜始まり。
  - 左側に時間別タイムテーブル、その下に日別の `気分`、`疲労度`、`睡眠` 欄を置く。
  - 日付欄 `B3:H3` は右寄せ。
  - 右側に `達成度合い（％）`、`英語`、`数学`、`国語`、`理科`、`社会`、`反省点` の横長メモ欄を置く。
  - 5教科の欄は同じ高さにそろえ、`達成度合い（％）` と `反省点` で高さを調整して下端をそろえる。
  - 白黒印刷前提のため、背景色は使わない。
  - 印刷範囲は `A1:N32`。

- `週間学習計画表生徒用_縦型.xlsx`
  - `生活記録表生徒用_縦型.xlsx` から派生させた週間学習計画表。
  - タイトルは `週間学習計画表（縦型）`。
  - 必要なシートは `縦型日曜始まり` と `縦型月曜始まり`。
  - `週目標` 欄、曜日別時間枠、教科欄を持つ。
  - `睡眠予定`、`達成度`、`振り返り` は削除済み。
  - 印刷範囲は `A1:H58`。

- `週間学習計画表生徒用_横型.xlsx`
  - 週間学習計画表のA4横版。
  - `横型日曜始まり` は日曜始まり、`横型月曜始まり` は月曜始まり。
  - 左側に時間別タイムテーブル、右側に結合セルを使った横長メモ欄を置く。
  - 日付欄 `B3:H3` は右寄せ。
  - 右側メモ欄は `週目標`、`英語`、`数学`、`国語`、`理科`、`社会`、`隙間`、`メモ`。
  - 白黒印刷前提のため、背景色は使わない。
  - 印刷範囲は `A1:N28`。

## 作業時の確認

Excel教材を編集するときは、次を確認する。

- `git status --short` で既存の未追跡・変更ファイルを見る
- 元ファイルを上書きするか、派生ファイルを作るかを区別する
- ユーザーがExcel上で手動調整した箇所を上書きしない
- 手作業の方が早い空シート削除や細かな見た目調整は、必要ならユーザー作業に任せ、Codexは最後の整合性確認を担当する
- Excelで開いたままの場合は保存できないため、閉じてもらってから再実行する
- A4縦、印刷範囲、余白、水平中央寄せ、行高、結合セル、罫線を確認する
- 英作文教材では、改頁後の次行が主語見出しになっているか、太い横罫線が実際の見出し行にだけあるか、注釈行のフォントが全ブロックで統一されているか確認する
- 可能なら `.xlsx` をレンダリングして見た目を確認する
- 数式エラー `#REF!`、`#DIV/0!`、`#VALUE!`、`#NAME?`、`#N/A` がないか確認する

## PDF化ツール

Excel教材を配布用PDFにする場合は、`PDF化ツール.bat` を使う。PowerShellに慣れていなくても、ダブルクリックまたはExcelファイルのドラッグで起動できる。

選べる形式:

- そのまま全ページPDF化
- シート名をしおりにして全ページPDF化
- シートごとに別々のPDF化

詳しい使い方は `scripts/README_PDF_TOOL.md` を参照する。

作成経緯、トラブル対応、今後の改善候補は `PDF化ツール_作業記録.md` に残している。
