# 数学 基本確認資料: 三角比・三角関数

出典: `三角比改訂版_改善版.pptx`

## 使う場面

数学で三角比、単位円、sin/cos/tan、角度変換、特殊角を扱うときに参照する。

## 基本関係

- 単位円では、半径1の円上の点を考える。
- 座標は横が `cosθ`、縦が `sinθ`。
- `tanθ = sinθ / cosθ`。
- `cosθ = 0` のとき `tanθ` は未定義。代表例は `90°`、`270°`。
- 基本式は `sin^2θ + cos^2θ = 1`。

## 角度変換の見方

- `90°` ずれ: `sin` と `cos` が入れ替わる。
- `180°` ずれ: 符号だけが反転する。
- `360°` ずれ: 元の値に戻る。
- 単位円上の位置を見て、正負を判断する。

## 特殊角の目安

- `0°`: `tanθ = 0`
- `30°`: `tanθ = 1/√3`
- `45°`: `tanθ = 1`
- `60°`: `tanθ = √3`
- `90°`: `tanθ` は未定義
- `120°`: `tanθ = -√3`
- `135°`: `tanθ = -1`
- `150°`: `tanθ = -1/√3`
- `180°`: `tanθ = 0`

## 解説で優先すること

- 公式だけでなく、単位円・座標・符号の理由を説明する。
- `tan` は「傾き」と関連づけると理解しやすい。
- 角度変換では、どの象限にあるかを先に確認する。
