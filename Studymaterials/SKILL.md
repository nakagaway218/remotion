# Studymaterials Workbook Layout

## 基本方針

Studymaterials の Excel 教材や生徒用記録表を編集するときは、元ファイルを不用意に壊さない。派生表を作る場合は別ファイルにする。

まず `git status --short` を確認し、ユーザーの未追跡ファイルや編集中ファイルを把握する。

Excelでユーザーが手動調整した箇所は、広範囲の再生成や一括整形で上書きしない。手作業の方が早い箇所、特に空シート削除、斜線セルの細かな文字位置、見た目の微調整は、ユーザー作業を尊重し、Codexは整合性確認と必要最小限の修正に回る。

## 生活記録表と計画表

`生活記録表生徒用_縦型.xlsx` は次の構成を前提にする。

- `縦型日曜始まり`: 日曜始まり
- `縦型月曜始まり`: 月曜始まり
- 不要な空シートは削除済み。再作成しない。

週間計画表へ転用する場合は、曜日並びと時間帯の枠を維持する。計画表では、生活記録向けの `睡眠予定`、`達成度`、`振り返り` が不要になることがある。

計画表の現在の推奨形:

- ファイル名: `週間学習計画表生徒用_縦型.xlsx`
- タイトル: `週間学習計画表（縦型）`
- タイトルは14pt・太字を基準にする
- 必要なシートは `縦型日曜始まり` と `縦型月曜始まり`
- `A2`: `週目標`
- `B2:H2`: 結合して週目標の記入欄にする
- `A2:H2`: 罫線を入れる
- 教科欄: `数学`、`英語`、`国語`、`理科`、`社会`、`隙間`

縦型生活記録表の現在の推奨形:

- ファイル名: `生活記録表生徒用_縦型.xlsx`
- タイトル: `生活記録表（縦型）`
- タイトルは14pt・太字を基準にする
- `縦型日曜始まり`: 日曜始まり
- `縦型月曜始まり`: 月曜始まり

横型計画表を作る場合:

- ファイル名: `週間学習計画表生徒用_横型.xlsx`
- `横型日曜始まり`: 日曜始まり
- `横型月曜始まり`: 月曜始まり
- 左側に `0:00` から `23:00` までの曜日別タイムテーブルを置く
- 右側に `項目` 列と横長結合メモ欄を置く
- 右側メモ欄は `週目標`、`英語`、`数学`、`国語`、`理科`、`社会`、`隙間`、`メモ`
- A4横1枚に収める
- 白黒印刷前提では背景色を使わない
- 日付欄 `B3:H3` は右寄せにする
- 左上の時間・日付交点は斜線罫線にし、右上に `日付`、左下に `時間` を入れる

横型生活記録表を作る場合:

- ファイル名: `生活記録表生徒用_横型.xlsx`
- `横型日曜始まり`: 日曜始まり
- `横型月曜始まり`: 月曜始まり
- 左側に `0:00` から `23:00` までの曜日別タイムテーブルを置く
- タイムテーブル下に日別の `気分`、`疲労度`、`睡眠` を置く
- 右側に `項目` 列と横長結合メモ欄を置く
- 右側メモ欄は `達成度合い（％）`、`英語`、`数学`、`国語`、`理科`、`社会`、`反省点`
- 5教科の欄は同じ高さにする
- `達成度合い（％）` と `反省点` の高さで全体を調整し、右側欄の下端をそろえる
- A4横1枚に収める
- 白黒印刷前提では背景色を使わない

## 印刷調整

A4縦1枚に収める場合は、内容を無理に縮める前に、不要な空白行と不要欄を削る。

推奨設定:

- A4縦
- `fitToWidth = 1`
- `fitToHeight = 1`
- `fitToPage = True`
- 左右余白を同じ値にする
- 水平中央寄せを有効にする
- 印刷範囲を明示する

今回の実績値:

- `週間学習計画表生徒用_縦型.xlsx`: `A1:H58`
- `週間学習計画表生徒用_横型.xlsx`: `A1:N28`
- `生活記録表生徒用_縦型.xlsx`: `A1:H61`
- `生活記録表生徒用_横型.xlsx`: `A1:N32`
- 左右余白: 0.35 inch

左右に寄って見える場合は、片側の余白だけを変えず、左右余白を同値にして `horizontalCentered` を有効にする。

内容量が少なくページ上部に寄って見える教材では、上下余白をそろえたうえで `verticalCentered` を有効にする。英作文教材の派生では、ページごとの余白バランスを印刷プレビュー前提で確認する。

## 英作文教材の派生

`中学生英作文be動詞現在形編.xlsx` などから新しい英作文教材を派生させる場合、セル値の置換だけで終わらせない。行数や回答欄の数が変わるため、改頁、太い横罫線、注釈行の書式を再計算して反映する。

一般動詞現在形編の実績:

- ファイル名: `中学生英作文一般動詞現在形編.xlsx`
- 基本文: `私はテニスをします。`
- シート: `問題一般動詞`、`解答回答一般動詞`
- 改頁位置: `32, 62, 92, 122`
- 太い横罫線の行: `1, 3, 18, 33, 48, 63, 78, 93, 108, 123`
- 注釈行: `4, 19, 34, 49, 64, 79, 94, 109, 124`

改頁は、次ページの開始見出し行ではなく、その1行前に入れる。たとえば見出しが `33` 行目から始まる場合、改頁IDは `32` にする。

太い横罫線は、元ブックの古いブロック位置に残ることがある。派生後は全行の太罫線を確認し、タイトル行と実際の主語見出し行だけに置き直す。

罫線は太さだけでなく色も確認する。be動詞現在形編では、タイトル行と主語見出し行の上罫線は黒の中太、通常行の上下罫線は薄いグレーになっている。派生教材で通常行の `thin` 罫線が黒のまま残ると、印刷時に全体が太く見える。左右の縦外枠は同じ黒の中太にそろえる。結合セルでは右端の見た目がアンカーセル側の罫線に依存することがあるため、PDFで左右端の見え方を確認する。

注釈行は、1つ目のブロックだけでなく全ブロックに同じフォントを適用する。斜体などの書式差は印刷時に目立つため、`font.italic` などを行リストで検査する。

英作文教材のフォント分類は、基準ブックである `中学生英作文be動詞現在形編.xlsx` に合わせる。タイトルは `14pt`、主語見出しは `12pt`、注釈行は `10pt` 斜体、本文・回答欄・正解欄は `11pt`、太字なしを基準にする。派生元に書式の乱れがある場合、派生先にも引き継がれるため、セル値の置換後に全行の分類検査を行う。

`私` / `私たち` を主語にした疑問文は、返答者から見ると `you` で答えるのが自然になる。英作文教材で `Am I ...?`、`Are we ...?`、`Do I ...?`、`Do we ...?` などを扱う場合は、解答を `I` / `we` のままにしない。必要に応じて、相手が答える形なので返答では `I / we` ではなく `you` を使う、という注釈を入れる。

助動詞と書き換え表現を扱う教材では、作成前に「基本形・否定文・疑問文・Yes/No返答」それぞれについて、元の助動詞と書き換え表現の両方に基本形と短縮形が必要かを表で確認する。特に否定文と疑問文への「いいえ」の返答は短縮形を落としやすい。

確認例:

- `will`: `will not` / `won't`
- `be going to`: `am not going to`, `is not going to` / `isn't going to`, `are not going to` / `aren't going to`
- `can`: `cannot` / `can't`
- `be able to`: `am not able to`, `is not able to` / `isn't able to`, `are not able to` / `aren't able to`

言い換え表現を追加するときは、肯定文だけでなく、書き換え後の否定短縮形、疑問文、疑問文への返答まで行を用意してから行高・改頁を決める。あとから短縮形を差し込むと、改頁や余白調整がやり直しになりやすい。

現在完了形では、疑問文への返答を全文だけで固定しない。`have not` / `haven't` の後ろは自然に省略できることがあるため、教材では省略可能な部分を括弧で示す。たとえば経験用法では、`No, I have not (visited Kyoto before).`、`No, I haven't (visited Kyoto before).`、回数疑問文へのゼロ回答では `I have not (visited Kyoto before).`、`I haven't (visited Kyoto before).` のようにする。`never` は `I have never visited Kyoto.` のように目的語句まで必要なので、ここは括弧化しない。Yes/No疑問文と `How many times ...?` の返答を別々に確認する。

注釈が長くなる場合は、既存の注釈を消さずに2行に分ける。折り返しを有効にし、行高を2行分に広げて、印刷時に2行とも見えるようにする。注意書きの文面は長くしすぎず、文法説明と会話上の注意を2行以内で収める。一般動詞現在形編と現在進行形編では、注意書き行は行高 `36` を基準にする。

## 行高と余白

文字が潰れる場合は、該当行を広げるだけでなく、不要行を削って高さを回す。

計画表では、睡眠行・達成度行・振り返り行を削除し、週目標と教科欄に高さを回した。削除後に行高が前の小さい行から引き継がれることがあるので、教科行の高さは必ず再設定する。

英作文教材で余白が目立つ場合、最初にシート全体の縮小率で合わせない。縮小をかけると文字サイズと余白の判断がずれ、あとで列削除・列幅・行高調整をやり直すことになりやすい。まず表示倍率・印刷倍率を100%基準に戻し、不要列を削るか印刷範囲を狭め、列幅と行高でページ内の密度を整える。最後に必要な場合だけ、印刷設定として `fitToWidth` を使う。

## 検証

編集後に最低限これを確認する。

- 日曜始まりシートと月曜始まりシートの両方に同じ意図の変更が入っている
- シート名で日曜始まり・月曜始まりを区別できる
- 週目標欄の `B2:H2` が結合されている
- 週目標欄に罫線がある
- 不要な小さい空白行が印刷範囲に残っていない
- 教科行の高さがそろっている
- 印刷範囲、A4縦、横1ページ、縦1ページ、左右同余白、水平中央寄せが設定されている
- 必要に応じて垂直中央寄せが設定され、印刷時に上寄せになっていない
- 縦型・横型のタイトル表記が一致している
- 横型の日付欄 `B3:H3` が右寄せになっている
- 英作文教材では、改頁後の次行が主語見出し行になっている
- 英作文教材では、太い横罫線がタイトル行と主語見出し行だけにある
- 英作文教材では、通常行の罫線色が薄いグレーで、区切り行だけ黒くなっている
- 英作文教材では、外枠の左右・上下の太さに違和感がないか確認し、違和感があればユーザーに提案する
- 英作文教材では、タイトル・主語見出し・注釈行・本文/回答欄のフォント分類が全ブロックで統一されている
- 英作文教材では、`私` / `私たち` の疑問文に対する返答が、相手から見て自然な `you` になっている
- 英作文教材では、会話上の注意を注釈に入れる場合、既存注釈を消さず、必要なら2行化して行高を調整している
- 英作文教材の助動詞・書き換え教材では、元の助動詞と書き換え表現の両方について、否定短縮形と疑問文への否定返答の短縮形が抜けていない
- 英作文教材の現在完了形では、`have not` / `haven't` 返答の省略可能部分を括弧で示し、`never` 行は全文のままにしている
- 英作文教材の現在完了形では、Yes/No疑問文への否定返答だけでなく、`How many times ...?` への「一度もありません」の返答にも同じ括弧ルールを適用している
- 英作文教材では、余白対策として縮小率だけで逃げていない。100%基準で不要列、印刷範囲、列幅、行高を確認してから改頁を決めている
- 英作文教材では、Excel COMでPDF化し、PNGにレンダリングした代表ページで注意書きがセル内に収まるか確認する
- ユーザーが手動削除した空シートや手動調整した斜線セルを復元していない
- `#REF!`、`#DIV/0!`、`#VALUE!`、`#NAME?`、`#N/A` がない

Excelでブックが開いていると保存時に `PermissionError` が出る。その場合はユーザーに対象ブックを閉じてもらってから同じ処理を再実行する。

## 日本語助動詞一覧.xlsx の注意

`日本語助動詞一覧.xlsx` を作成・修正するときは、先に内容確認、後で体裁調整の順にする。

内容確認:

- 助動詞名、分類、現代口語、文語対応を列単位で一覧化する。
- 意図しない重複がないか確認する。
- `たい` / `たがる`、`ている` / `てある`、断定 `なり` と伝聞・推定 `なり` を重点的に確認する。

体裁調整:

- ユーザーに最終印刷条件を確認する。A4縦1枚、A4縦複数枚、A4横、A3では最適解が変わる。
- 一度に多くの体裁指示を反映しない。用紙、列幅、行高、改行、縮小表示、色の順に進める。
- 列幅は、最大1行・最大2行・最大3行の列で分類し、同じ分類内の列幅をそろえる。
- 印刷ページ表示で上下余白が大きい場合は、行高を少しずつ増やす。一気に増やすとExcelの自動縮小で文字が小さくなる。
- セル内改行を含むセルで、ダブルクリックしないと表示が直らない場合は、縮小表示を外す。特に縦書き方向、折り返し、固定行高、縮小表示の併用に注意する。
- A列や見出し行の塗りが濃い場合は、白黒印刷でも読める薄い背景と黒文字にする。

ユーザーが一度に多くの調整指示を出した場合は、すぐ一括反映せず、優先順を短く整理してから進める。

## 仕上げの役割分担

次のように役割を分けると、トークン消費と作業時間を抑えながら品質を保てる。

- ユーザー: Excel上での見た目判断、空シート削除、斜線セルの細部調整
- Codex: シート名・タイトル・印刷設定・余白・印刷範囲・エラー文字列・両シート反映の確認

ユーザーが「手動で調整した」と伝えた後は、まず差分を読み取り、必要な範囲だけ修正する。見た目全体を再構築しない。
