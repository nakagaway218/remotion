# Studymaterials AI Context

## 生活記録表・週間学習計画表の作成経緯

`生活記録表生徒用_縦型.xlsx` は、週単位の生活記録表として作られている。

- `縦型日曜始まり`: 日曜始まり
- `縦型月曜始まり`: 月曜始まり
- 不要な空シートは削除済み

この形式は、生活記録だけでなく週間学習計画表にも転用できる。時間帯の縦軸と曜日の横軸を残し、下部の教科欄を計画記入欄として使う。

## 今回作成した派生ファイル

`週間学習計画表生徒用_縦型.xlsx` を、元の `生活記録表生徒用_縦型.xlsx` とは別ファイルとして作成した。

主な変更:

- タイトルを `週間学習計画表` に変更
- `縦型日曜始まり` / `縦型月曜始まり` の曜日構成は維持
- `週目標` 行を追加し、`B2:H2` を結合した記入欄にした
- `A2:H2` に罫線を入れた
- `睡眠予定`、`達成度`、`振り返り` は計画表では不要として削除
- 教科欄は `数学`、`英語`、`国語`、`理科`、`社会`、`隙間` を残した
- 小さい空白行を削除し、印刷範囲を `A1:H58` に詰めた

## 印刷レイアウト方針

生活記録表・計画表とも、印刷時に左右の偏りが出やすい。調整時は次を確認する。

- A4縦
- 横1ページ、縦1ページに収める
- 印刷範囲を明示する
- 左右余白を同じ値にする
- 水平中央寄せを有効にする

今回の設定:

- `週間学習計画表生徒用_縦型.xlsx`: 印刷範囲 `A1:H58`
- `生活記録表生徒用_縦型.xlsx`: 印刷範囲 `A1:H61`
- 左右余白: 0.35 inch
- 水平中央寄せ: 有効

## 英作文教材の派生作成

`中学生英作文一般動詞現在形編.xlsx` は、`中学生英作文be動詞現在形編.xlsx` から派生させた。

基本例文は `私はテニスをします。`。主語別に、肯定文、否定文、疑問文、Yes/No の返答を練習する。三単現の主語では `plays`、否定文では `does not / doesn't`、疑問文では `Does ... play ...?` を使う。

派生時に起きた注意点:

- 行数が変わるため、元ブックの改頁位置をそのまま使わない。
- Excel の手動改頁は「指定行の後で改頁」なので、次ページの見出し行の1行前に入れる。
- 一般動詞現在形編では、改頁位置は `32, 62, 92, 122`。
- 元ブックの太い横罫線が古いブロック位置に残ることがある。タイトル行と実際の主語見出し行だけに置き直す。
- 一般動詞現在形編の太い横罫線は `1, 3, 18, 33, 48, 63, 78, 93, 108, 123`。
- 内容がページ上部に寄る場合は、上下余白をそろえ、垂直中央寄せを有効にする。
- 注釈行のフォントは全ブロックで統一する。一般動詞現在形編では `4, 19, 34, 49, 64, 79, 94, 109, 124` を斜体にした。
- `私` / `私たち` の疑問文は、実際の会話では相手が `you` で答えるのが自然になる。解答では `I` / `we` のままにせず、`you` に直す。該当ブロックには、相手が答える形なので返答では `I / we` ではなく `you` を使う、という注釈を入れる。
- 注釈が長くなる場合は、既存注釈を消さずに2行化する。行高を広げ、折り返しと垂直中央寄せを確認する。今回の該当注釈行は行高 `36` にした。

## 横型計画表

`週間学習計画表生徒用_横型.xlsx` を、A4横1枚用の派生ファイルとして追加した。

- `横型1`: 日曜始まり
- `横型2`: 月曜始まり
- 左側: `0:00` から `23:00` までの曜日別タイムテーブル
- 右側: ラベル列と横長結合メモ欄
- 右側メモ欄: `週目標`、`英語`、`数学`、`国語`、`理科`、`社会`、`隙間`、`メモ`
- 印刷範囲: `A1:N28`
- 印刷設定: A4横、横1ページ、縦1ページ、左右同余白、水平・垂直中央寄せ
- 白黒印刷前提なので背景色は使わない
- 日付欄は右寄せにする
- 左上の時間・日付の交点は斜線罫線にし、右上に `日付`、左下に `時間` を入れる

横型では、教科別の計画は1週間分をまとめて右側に書く。日別に必要な睡眠・疲労度などは生活記録表の横型を作るときにタイムテーブル下へ置く方針。

## 横型生活記録表

`生活記録表生徒用_横型.xlsx` を、A4横1枚用の派生ファイルとして追加した。

- `横型1`: 日曜始まり
- `横型2`: 月曜始まり
- 左側: `0:00` から `23:00` までの曜日別タイムテーブル
- タイムテーブル下: 日別の `気分`、`疲労度`、`睡眠`
- 右側: ラベル列と横長結合メモ欄
- 右側メモ欄: `達成度合い（％）`、`英語`、`数学`、`国語`、`理科`、`社会`、`反省点`
- 5教科の欄は同じ高さにする
- `達成度合い（％）` と `反省点` の高さで全体を調整し、下端をそろえる
- 印刷範囲: `A1:N32`
- 印刷設定: A4横、横1ページ、縦1ページ、左右同余白、水平・垂直中央寄せ
- 白黒印刷前提なので背景色は使わない

記録表では、睡眠・疲労度・気分は1日ごとに必要になるため、右側の週まとめ欄ではなく曜日列の下に置く。

## シート名と日付欄の最終調整

ユーザーが、記録表・計画表の各ファイルについて、日曜始まりと月曜始まりをシート名で区別できるように手動で修正した。今後は `縦型1` / `縦型2`、`横型1` / `横型2` ではなく、曜日始まりが読めるシート名を前提にする。

現在の意図:

- 縦型: `縦型日曜始まり`、`縦型月曜始まり`
- 横型: `横型日曜始まり`、`横型月曜始まり`

横型では、日付記入欄 `B3:H3` の `月　日(日)` などを右寄せにする。今回、横型計画表・横型記録表の両方で右寄せになっていることを確認した。

## 検証メモ

調整後は次を確認する。

- `git status --short` で未追跡・変更ファイルを把握する
- Excelが開いている場合、保存時に `PermissionError` が出るので、ユーザーに閉じてもらう
- `openpyxl` でシート、行高、印刷範囲、余白、水平中央寄せを確認する
- 英作文教材では、改頁後の次行が見出し行か、太い罫線が実際の見出し行にあるか、注釈行の書式が全ブロックでそろっているか確認する
- 英作文教材では、`I` / `we` の疑問文に対する返答が会話上自然な `you` になっているか確認する
- `@oai/artifact-tool` で `.xlsx` を読み込み、可能なら画像プレビューを確認する
- `#REF!`、`#DIV/0!`、`#VALUE!`、`#NAME?`、`#N/A` を検索して数式エラーを確認する

## 仕上げ工程で得た運用判断

Excel教材の微調整では、すべてをCodex側で自動処理するより、ユーザーがExcel上で直接触った方が早く確実な箇所がある。特に、空シート削除、斜線セルの細かな文字位置、表示上の微妙な見た目確認は、ユーザーの手作業とCodexの検証を組み合わせると効率がよい。

今回の最終仕上げでは次の方針が有効だった。

- ユーザーが手作業で直した箇所は、再生成や広範囲の整形で上書きしない
- Codexは、シート構成、タイトル、印刷範囲、余白、1ページ設定、数式エラーの有無など、見落としやすい機械的チェックを担当する
- 手動で削除済みの無駄なシートは、再度作成したり復元したりしない
- 縦型・横型のタイトル表記はそろえる
  - `週間学習計画表（縦型）`
  - `週間学習計画表（横型）`
  - `生活記録表（縦型）`
  - `生活記録表（横型）`
- タイトルは横型に近い見え方にするため、14pt・太字を基準にする

次回以降、似た作業では「自動化で直す部分」と「ユーザーが手で見た目を整える部分」を分けて進める。Codexは最後に整合性チェックを行い、必要なら `README.md` と `SKILL.md` に反映する。
