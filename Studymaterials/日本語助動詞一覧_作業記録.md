# 日本語助動詞一覧 作業記録

対象ファイル: `日本語助動詞一覧.xlsx`

## 2026-06-19 の反省点

このファイルの作成・修正では、次の問題が起きた。

- 助動詞・対応列の重複を見落とした。
- 最初から一度に多くの体裁指示を処理しようとして、列幅・行高・縮小表示・改行方針が何度も揺れた。
- 印刷プレビュー上の見え方と、機械的に確認した行高・列幅の値だけでは判断がずれる箇所があった。
- Excelでブックを開いたまま修正しようとして、保存時にロックされる場面が繰り返し発生した。

## 再発防止ルール

### 1. 内容確認を先に終わらせる

体裁調整に入る前に、まず内容の正しさを確認する。

- 助動詞名・分類・文語対応に重複や欠落がないか確認する。
- 現代口語と文語の対応が不自然でないか確認する。
- `たい` / `たがる`、`ている` / `てある`、断定 `なり` と伝聞・推定 `なり` など、混同しやすい組を重点確認する。
- 表全体を列単位で一覧化し、同じ語が意図せず重複していないか確認する。

### 2. 指示は段階に分ける

一度に多くの体裁指示を反映しない。次の順に分ける。

1. 内容修正
2. 用紙サイズとページ数の決定
3. 列幅の基準決定
4. 行高の調整
5. 改行・縮小表示の調整
6. 色・罫線・印刷範囲の最終確認

各段階で、変更対象と確認結果を短く報告してから次へ進む。

### 3. 列幅は分類基準を先に決める

今回の最終調整では、列幅を次の考え方でそろえた。

- 最大1行の列: 同じ幅
- 最大2行の列: 同じ幅
- 最大3行の列: 同じ幅

ただし、印刷ページで実際に読みにくい列がある場合は、ユーザー確認を挟んで例外を設ける。

### 4. 改行と縮小表示を混ぜすぎない

次の組み合わせは表示が不安定になりやすい。

- セル内改行
- 折り返し
- 縮小表示
- 縦書き方向
- 固定行高

特に `S13`、`S15` のように2行で見せるセルは、行高と列幅が足りているなら縮小表示を外す。ダブルクリックしないと表示が直らない場合は、まず縮小表示を疑う。

### 5. 印刷プレビュー前提で確認する

Excelの値として行高・列幅が整っていても、印刷ページ表示では見え方が変わる。体裁作業では次を確認する。

- A4縦1枚に収まるか
- 上下左右の余白が不自然でないか
- 1語が途中で折れていないか
- 別語の並列は、必要に応じてセル内改行で見せる
- A列や1行目の背景色が濃すぎず、文字が読めるか

## 次回の進め方

次回、同じようなExcel教材を作るときは、最初に次をユーザーへ確認する。

- まず内容の正確さを優先するか、印刷体裁も同時に作るか
- A4縦1枚、A4縦複数枚、A4横、A3など、最終印刷条件
- 文字が小さくても1枚に収めるか、読みやすさ優先で複数枚にするか
- 列幅を語数別にそろえるか、語の長さに合わせて個別調整するか

この確認が終わるまでは、広範囲の体裁調整を一括で進めない。
