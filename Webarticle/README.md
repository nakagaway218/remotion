# Web記事作成ツール

`Web記事作成.xlsx` の記事作成手順を、ローカルで順番に実行するための試作ツールです。
標準導線は ChatGPT に貼り付けるプロンプトを作る手動連携モードです。

## 起動

PowerShell でこのフォルダーを開いて起動します。

```powershell
node server.mjs
```

ブラウザーで `http://localhost:4173` を開きます。

ダブルクリックで使う場合は、`A_Webarticle_Start.cmd` を開くとサーバー起動とブラウザー表示をまとめて行います。
`A_Webarticle_Index.html` は、サーバーがすでに起動しているときにブラウザーで開く入口です。

## 使い方

1. キーワードを入力します。
   上部で目標文字数、本文の分量配分、記事用途、トーンも指定できます。
2. 専門性が高い記事では、基礎知識ステップの `情報ソース候補プロンプト` で、NotebookLMへ読み込ませる重要ソース候補を先に整理します。
   その後、`リサーチセット作成` または `NotebookLM用プロンプト` を使い、NotebookLM にソースを読み込ませて作成されたメモを貼り戻します。
   手元の文献・資料がある場合は、`資料読込` で txt / md / csv を読み込むか、抜粋を貼り付けます。
   通常の記事では空欄のまま次へ進めます。
3. 各ステップでプロンプト作成ボタンを押し、プロンプトを ChatGPT に貼り付けます。
4. ChatGPT の出力をステップの保存欄へ貼り戻します。
5. 構成ステップでは、ラッコから手動で出した CSV/JSON を「CSV/JSON読込」で入れるか、ChatGPTのラッコ連携GPTsへ「ラッコGPTs用プロンプト」を貼って結果を戻します。
   `RAKKO_API_KEY` をこのツール側に設定している場合は、「ラッコから取得」で検索上位記事の見出し構成を直接入れられます。
6. 構成の次にあらすじを作り、必要なら修正プロンプトで直してから「このあらすじを採用」を押します。
   採用したあらすじだけが後工程で使われます。
7. タイトル案から採用タイトル欄へ1つ入れます。
8. 本文は構成から h2 ごとに見出しを貼り付け、必要なら見出し別文字数も指定します。
9. 右側の下書きをコピーまたは Markdown で保存します。
   本文の前に `本文前チェック` でタイトル、構成、あらすじの整合を確認します。
   `プロジェクト保存` を押すと、作業中の中間成果物を `article-projects` にまとめて保存できます。

## NotebookLMで基礎知識を作る場合

- 基礎知識ステップは、医療、美容、法律、金融、専門サービスなど、内容の正確さが重要な記事向けです。
- この工程では OpenAI API を使いません。NotebookLM にプロンプトを貼り、返ってきたメモをツールへ貼り戻します。
- `情報ソース候補プロンプト` を使うと、公的機関、専門団体、一次情報、専門家解説など、NotebookLMに読み込ませる候補を整理できます。
- `重要情報ソースリスト` には、URL、資料名、信頼できる理由、記事で使う観点を残します。
- `インポートした文献・資料` には、資料の本文、抜粋、要約、URL、出典メモを入れられます。
- 貼り戻したメモ、重要情報ソースリスト、文献・資料は、検索意図、構成、あらすじ、タイトル、リード文、本文、まとめのプロンプトに自動で入ります。
- ラッコCSV/JSONを読み込んだ後、`リサーチセット作成` を押すと、NotebookLMへ貼る調査依頼文と参考URL一覧を作成できます。
- メモが不要な記事では空欄のまま進められます。

## ChatGPT手動連携

- 標準モードでは OpenAI API キーは不要です。
- このツールは入力内容を整理して、ChatGPT に貼るためのプロンプトを作ります。
- ChatGPT の回答は各ステップの保存欄へ貼り戻して次へ進みます。
- 「API生成」は `API生成の詳細設定` を開いた場合だけ表示する予備機能です。

## 費用制限

- 以下は「API生成」を使う場合だけ必要です。
- 既定モデルは低コストな `gpt-5-mini` です。さらに費用を下げたい場合は画面で `gpt-5-nano` を選べます。
- `OPENAI_COST_CAP_USD` は、このツールが保存した推定使用額の上限です。既定値は `$1.00` です。
- 生成前に上限を超えそうなリクエストは停止します。
- 生成ごとに OpenAI の使用トークン数から推定費用を `data/usage.json` に保存します。
- `OPENAI_MAX_OUTPUT_TOKENS` を設定すると、1回の生成出力上限をさらに下げられます。既定値は `2400` です。

```powershell
$env:OPENAI_MAX_OUTPUT_TOKENS="1200"
```

## ラッコ連携

- ラッコキーワードから手動でダウンロードした見出し CSV/JSON は、構成ステップの `CSV/JSON読込` で読み込めます。
- CSV/JSON読込は上位5記事の見出しテキストへ整えて、検索上位記事の構成欄に入れます。
- `simple` 形式のように、rank/title/url/headline が行になっているタブ区切りCSVにも対応しています。
- UTF-16LE 形式で保存されたCSVにも対応しています。
- 読み込み時に、関連記事、人気記事、カテゴリー、タグ、商品一覧、SNSフォローなど、明らかなサイト共通導線は構成用テキストから除外します。
- ChatGPTのラッコキーワード連携GPTsを使う場合は、構成ステップの `ラッコGPTs用プロンプト` を作成してGPTsへ貼り、返ってきたJSONまたはh2/h3形式のテキストを `ラッコGPTs結果` に貼ります。
- `GPTs結果を反映` を押すと、検索上位記事の構成欄へ整形して入力します。
- `RAKKO_API_KEY` があると、構成ステップでラッコキーワードの見出し抽出 API から上位5記事の `h2`、`h3` を取得します。
- ラッコ API キーがない場合も、見出し欄へ手入力して続けられます。

```powershell
$env:RAKKO_API_KEY="your-rakko-api-key"
node server.mjs
```

## API生成を使う場合

```powershell
$env:OPENAI_API_KEY="your-openai-api-key"
$env:OPENAI_COST_CAP_USD="1.00"
$env:RAKKO_API_KEY="your-rakko-api-key"
node server.mjs
```

## 補足

- 生成結果は各欄で編集できます。
- 入力内容はブラウザーのローカル保存に残ります。
- `プロジェクト保存` は、`request.json`、`trusted-sources.md`、`knowledge.md`、`sources.md`、`rakko-gpts.md`、`search-intent.md`、`serp-analysis.md`、`outline.md`、`synopsis.md`、`preflight-check.md`、`article-plan.json`、`draft.md`、`review.json` を `article-projects/キーワード_日時/` に出力します。
