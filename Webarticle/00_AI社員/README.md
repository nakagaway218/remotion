# Webarticle AI社員

Web 記事制作に使う AI 社員の一覧です。

| AI 社員 | 呼び出しの目安 | 成果物 |
| --- | --- | --- |
| 記事要件編集者 | 目的や読者が曖昧なとき | `requirements.md` |
| 記事リサーチャー | 材料や根拠が必要なとき | `research.md` |
| 記事構成ディレクター | 見出しや流れを作るとき | `outline.md` |
| 記事ライター | 本文を書くとき | `draft.md` |
| ファクト・品質レビュー担当 | 公開前に確認するとき | `review.md` |
| 入稿整形担当 | WordPress / Google Docs 向けに整えるとき | `final.md` |
| 記事記録係 | 次回再開用にまとめるとき | `handoff.md` |

## 使い方

まず `../WORKFORCE_SPEC.md` を埋めます。

小さい作業では、必要な担当だけ使います。大きい記事や新規記事では、`AI_WORKFORCE.md` の標準フローに沿って進めます。
