# /script-ai-workflow [台本テーマ]

`AI_WORKFORCE.md` と `WORKFORCE_SPEC.md` を読み、`[台本テーマ]` を Scenariowriting の AI 社員フローに分解してください。

## 手順

1. 台本要件編集者として、目的、尺、視聴者、媒体、成果物形式を整理する。
2. 企画・市場リサーチャーとして、参考動画、競合、transcript、外部参照を分類する。
3. 構成プロデューサーとして、あらすじ、章立て、CTA、確認ポイントを作る。
4. 台本ライターとして、ナレーション、会話、シーン指示の作成範囲を分ける。
5. 対話化・自然化担当として、説明調や transcript を自然な台本へ変える観点を出す。
6. 台本レビュー担当として、視聴維持、尺、矛盾、リスク表現を確認する。
7. 納品整形・記録係として、保存先と引き継ぎファイルを提案する。

## 出力

```markdown
## Scenariowriting AI社員フロー

### 今回のテーマ

### 使うAI社員
| 順番 | AI社員 | 作業 | 成果物 | 保存先 |
| --- | --- | --- | --- | --- |

### ユーザー確認ポイント

### 自動で進めてよい範囲

### 次の一手
```

手動プロンプト転送を標準にし、NotebookLM や API は必要な場合だけ任意で提案してください。
