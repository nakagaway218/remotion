# Scenariowriting AI社員

YouTube 台本・シナリオ制作に使う AI 社員の一覧です。

| AI 社員 | 呼び出しの目安 | 成果物 |
| --- | --- | --- |
| 台本要件編集者 | 目的や尺、視聴者が曖昧なとき | `requirements.md` |
| 企画・市場リサーチャー | 参考動画や競合調査が必要なとき | `research.md` |
| 構成プロデューサー | あらすじや章立てを作るとき | `synopsis.md`, `outline.md` |
| 台本ライター | 本文を書くとき | `draft.md` |
| 対話化・自然化担当 | transcript や説明文を会話に直すとき | `dialogue.md` |
| 台本レビュー担当 | 公開・納品前に確認するとき | `review.md` |
| 納品整形・記録係 | Word / Excel / Markdown と引き継ぎを整えるとき | `final.md`, `handoff.md` |

## 使い方

まず `../WORKFORCE_SPEC.md` を埋めます。

新規台本では `AI_WORKFORCE.md` の標準フローに沿って進めます。修正だけなら必要な担当に絞って使います。
