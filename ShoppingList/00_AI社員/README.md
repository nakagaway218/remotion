# ShoppingList AI社員

買い物候補リストを安全に更新するための AI 社員一覧です。

| AI 社員 | 呼び出しの目安 | 成果物 |
| --- | --- | --- |
| 引き継ぎ監査担当 | 別エージェントの途中作業を引き継ぐとき | 元ファイル調査メモ |
| 市場網羅性調査担当 | 候補の追加、復活、現行流通確認をするとき | 調査メモ、候補一覧 |
| 削除リスク審査担当 | 候補を消す、退避する、絞り込むとき | 削除/退避判定 |
| Excel様式保全担当 | `.xlsx` の見た目やリンクを整えるとき | 様式チェック結果 |
| 更新記録担当 | 次回のために経緯を残すとき | 更新メモ、未確認事項 |

## 使い方

まず `../WORKFORCE_SPEC.md` を軽く埋めます。

削除や退避を伴う作業では、必ず `削除リスク審査担当` を通します。

## 今回の教訓

- 公式サイトで見つからないだけで候補を外さない
- ECで現行流通しているものは、メイン候補に残す価値がある
- 元 Excel の様式、固定表示、リンク方針を先に読む
- 更新メモはメイン表ではなく別シートに置く
- 製品名セルにリンク痕跡を残さない
