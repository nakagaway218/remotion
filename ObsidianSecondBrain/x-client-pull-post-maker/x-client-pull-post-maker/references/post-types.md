# Client-Acquisition X Post Types

Use these formulas after interviewing the user. Replace all placeholders with user-provided facts. If a placeholder is unknown, ask once or choose a safer non-proof post.

## 1. Results / Before-After

Formula:

```text
Beforeの悩み
↓
やったこと
↓
Afterの結果
↓
同じ状態の人への一言
```

Example shape:

```text
毎週3時間かかっていた〇〇作業、
今は〇〇で30分まで短縮できました。

やったのは難しい開発ではなく、
1. 入力を固定
2. 判断基準を文章化
3. 最後だけ人間確認
この3つ。

AI活用はツール選びより「手順化」が先です。
```

Use when the user has numbers, screenshots, deliverables, or a clear process.

## 2. Solution / Know-how

Formula:

```text
よくある失敗
↓
なぜ起きるか
↓
解決手順3つ
↓
自然な締め
```

Example shape:

```text
AI導入で止まる会社、
だいたい「何をAIに任せるか」が曖昧。

最初に見るのはこの3つでOK。
1. 毎週繰り返す作業
2. 判断基準が文章にできる作業
3. 最後に人間確認できる作業

ここに当てはまるものから自動化する。
ツール選びはその後でいい。
```

Use most often. This is the main trust-building post type.

## 3. Portfolio / Work Sample

Formula:

```text
作ったもの
↓
誰の何に効くか
↓
工夫した点
↓
自然な締め
```

Example shape:

```text
中小企業向けに、問い合わせ前のAI診断フォームを作りました。

狙いは「何を相談すればいいか分からない」を潰すこと。
回答内容から、
・自動化できる業務
・必要なツール
・初回に見るべき数字
まで整理できます。

相談前の迷いを減らすなら、入口の設計から変える。
```

Use when the user can show a build, document, form, LP, dashboard, deck, prompt, or workflow.

## 4. Positioning / Profile

Formula:

```text
誰向けか
↓
何を解決するか
↓
どういう方法か
↓
相談前に見るべきもの
```

Example shape:

```text
中小企業・個人事業主向けに、
AIで「毎週繰り返している事務作業」を減らす支援をしています。

いきなり大規模導入ではなく、
まずは1業務だけ手順化して、
人間確認を残したまま小さく自動化する方針です。

AI活用で迷う時は、まず繰り返し作業を1つ書き出す。
```

Use for pinned posts, profile refreshes, and recurring "what I do" posts.

## 5. Client Voice / Order / Thanks

Formula:

```text
相談・依頼・感想を受けた事実
↓
相手が不安だった点
↓
解決した点
↓
感謝 or 学び
```

Example shape:

```text
「AIを入れたいけど、何から触ればいいか分からない」
という相談をいただきました。

最初にやったのはツール紹介ではなく、
毎週発生している作業の棚卸し。

AI導入は派手なことより、
現場の1時間を確実に減らす設計の方が喜ばれます。
まず見るのは、ツールではなく現場の作業。
```

Use only with permission-safe details. Anonymize client and confidential facts.

## 6. Work Style / Personality

Formula:

```text
仕事で大事にしている姿勢
↓
具体的な行動
↓
それが顧客にどう効くか
```

Example shape:

```text
AI活用支援で一番大事にしているのは、
「お客さんが自分で直せる状態」にすることです。

作って終わりだと、少し画面が変わっただけで止まる。
だから手順書、判断基準、修正方法まで一緒に残します。

便利な仕組みより、続く仕組みに寄せる。
```

Use about 10% of the time. It helps readers choose the person, not only the skill.

## 7-Day Pull Posting Plan

Use this when the user wants consistency or Record & Replay scheduling.

| Day | Type | Goal |
| --- | --- | --- |
| 1 | Solution / Know-how | Establish usefulness |
| 2 | Results / Before-After | Show proof |
| 3 | Solution / Know-how | Answer a buyer pain |
| 4 | Portfolio / Work Sample | Make the work visible |
| 5 | Positioning / Profile | Clarify who to ask |
| 6 | Solution / Know-how | Build repeat trust |
| 7 | Client Voice or Work Style | Reduce anxiety / show personality |

Keep the week value-heavy. Do not publish multiple direct promotion posts in a row.
