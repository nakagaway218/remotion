# Web Clip Index

Google Driveに保存した重い素材への軽い索引を置くフォルダです。

## 書くもの

- 元URL
- タイトル
- 保存日
- 保存理由
- Google Drive上の保存先
- 短い要点メモ

## 書かないもの

- 記事本文の丸ごとコピー
- 大量の引用
- PDF、画像、動画、音声などの重いファイル
- 個人情報や公開すべきでない情報

## テンプレート

```md
---
type: source
status: 未整理
date: YYYY-MM-DD
source_type: article

drive_url:

---
```
