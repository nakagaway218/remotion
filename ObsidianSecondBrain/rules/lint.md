# Lint

週に一度、または `raw/` に素材を大量投入した後に、Vault全体の健康診断をします。

## チェック観点

1. 矛盾: 別ページで定義や数値が食い違っていないか。
2. 欠落: 何度も出る重要テーマなのに専用ページがないものはないか。
3. 重複: 似たページが増えすぎていないか。
4. 古い情報: 出典や日付が古く、更新確認が必要なものはないか。
5. 新規候補: MOCや概念ページに分ける価値があるテーマはないか。

## 出力先

`wiki/lint-issues.md` に次の形で残します。

```markdown
# Lint Issues (YYYY-MM-DD)

## 矛盾
- [ ] 内容（関連: [[ページA]], [[ページB]]）

## 欠落
- [ ] テーマ: 理由

## 重複
- [ ] [[ページX]] と [[ページY]]

## 古い情報
- [ ] [[ページZ]]

## 新規候補
- [ ] テーマ: 理由
```

削除や統合は自動で行わず、提案してから実行します。
