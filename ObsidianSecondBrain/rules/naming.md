# Naming

ノートは「あとで見つける」ために名前とメタ情報を整えます。

## ファイル名

基本形:

```text
YYYY-MM-DD-種類-主題.md
```

例:

```text
2026-06-15-調査-Obsidian第二の脳.md
2026-06-15-会議録-教材企画.md
2026-06-15-意思決定-Vault運用方針.md
```

## frontmatter

各ノートの冒頭に、AIが読み取りやすいメタ情報を置きます。

```markdown
---
type: 調査
status: 参照用
date: 2026-06-15
topic: Obsidian
tags: [obsidian, ai-second-brain]
---
```

## 探すための4要素

| 要素 | 意味 |
|---|---|
| type | ノートの種類 |
| date | いつの情報か |
| topic | 何についてか |
| status | 進行中、参照用、完了、保留など |

## 原則

- フォルダを増やしすぎず、`[[wikilink]]` と命名でつなぐ。
- 既存ノートを一気に直さず、次に触る1枚から整える。
- タグは増やしすぎない。複数ノートで使うものだけ残す。
