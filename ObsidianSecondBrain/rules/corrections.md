# Corrections

ユーザーから受けた恒久的な修正指示を蓄積します。AIは作業前にここを読み、同じことを繰り返さないようにします。

## 書き方

```markdown
## YYYY-MM-DD
- 指摘:
- 今後:
```

## 初期ルール

## 2026-06-15
- 指摘: ObsidianやNotionの考え中メモと、Codexに読ませたい確定情報を混ぜない。
- 今後: Obsidianは思考・個人メモ、GitHub内MarkdownはCodex用の確定文脈として扱い、配置理由を明記する。

## 2026-06-25
- 指摘: Codexに読ませたい第二の脳は `Myownproject/ObsidianSecondBrain` に固定し、今後もこのフォルダで続ける。
- 今後: `raw/` はWebクリップ、YouTube、外部URLの出典メモ、`reports/` は要約・判断メモ・Codexに読ませたい整理済み情報、`wiki/` は恒久ノート・MOC・概念ページとして使う。個人的な走り書きや非公開メモは別の個人VaultまたはGit管理外に置く。
