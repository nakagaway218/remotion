# Codex完全攻略 120分版の要点

## 要約

動画は、Codexを初めて使う人向けに、全体像、導入方法、基本操作、成功例、失敗例、安全運用を順番に説明する総合ガイド。

主な内容は次の通り。

- Codexは「説明するだけのチャットAI」ではなく、ファイルを読んで、コードを書き、実行し、保存まで進めるAIエージェントとして説明されている。
- 利用形態は、CLI、IDE拡張、デスクトップアプリ、クラウド、モバイルの5系統として整理されている。初心者はデスクトップアプリかIDE拡張から始める想定。
- 基本操作は「開く、頼む、差分を見る、承認する、テストする、コミットする」の6段階で説明されている。
- 成功しやすい作業は、毎日・毎週繰り返す定型作業、文言修正、テスト作成、古いコードの移行、ドキュメント作成、表やデータ整理など。
- 成功例に共通する条件は、ゴールが明確、`AGENTS.md` や `agents.md` 的なルールがある、小さく試して広げる、差分を人間が確認すること。
- 失敗例として、丸投げ、承認の省略、前提不足、出力の鵜呑み、APIキーやパスワードの露出が挙げられている。
- 「完全無料」や非公式ツールにAPIキーを入れる危険性が強調されている。APIキー流出は高額請求や悪用につながるため、公式経路と秘密情報管理が必須。

## 自分の運用への反映

- Codexに任せる前に、依頼を「1つの小さな完了条件」に分ける。
- 変更前に対象ファイル、変更範囲、触ってはいけない場所を明示する。
- 変更後は `git diff` や差分確認を必ず通し、必要に応じて `git diff --check` を使う。
- APIキー、OAuthトークン、パスワード、顧客情報、個人情報はGitにもチャットにも貼らない。
- 初心者向けの導入説明としては有用だが、モデル名、料金、機能名、提供範囲は動画内情報であり、公式確認済みとして扱わない。
