# Claude CodeとObsidianで一次情報からコンテンツを作る

## 要約

- 動画の中心は、Obsidianを「冷蔵庫」、Claude Codeを「料理人」として扱う比喩。Obsidianに一次情報や口調サンプルを蓄積し、Claude Codeがそれを素材に記事や台本を作る。
- 毎回プロンプトに前提、参考記事、口調、過去資料を貼るのではなく、ObsidianのMarkdownファイルとして参照できる状態にしておく。
- Web Clipperで記事をObsidianに保存し、関連ファイルをリンクでつないだ上でClaude Codeに渡す流れが紹介されている。
- 価値あるコンテンツを作るには、ネット上の薄い情報ではなく、自分の体験、セミナー文字起こし、過去記事などの一次情報が重要。
- Obsidianのリンク機能、バックリンク、Omnisearch、Excalidrawなどのプラグインも紹介されている。

## 自分の運用への反映

- Google Driveに保存した文字起こしDocsを、Git側では要約とリンクだけにする今の方式は、一次情報の再利用に向いている。
- コンテンツ化する素材は、`raw/webclip-index/` から `reports/source-summaries/`、必要に応じて `wiki/` へ昇格させる。
- 記事や教材に使うときは、出典リンク、要約、自分の解釈を分けて記録する。

## 注意点

- Web Clipperで取得した記事本文をGitに丸ごと保存しない。
- 口調再現や過去資料活用は便利だが、公開前に権利、個人情報、誤字脱字を確認する。
