# Zip Inspections

Google DriveやSpreadsheetから見つかったZip素材について、Zip本体や展開物をGitに入れず、ファイル一覧と判断メモだけを残す場所です。

## ルール

- Zip本体と展開物はGitに保存しない。
- 実行ファイルやスクリプトは実行しない。
- レポートには、ファイル一覧、サイズ、読み取り候補、注意点だけを残す。
- 内容を読む場合も、全文コピーではなく要約や判断メモに変換する。
