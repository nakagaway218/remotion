# スケジュールPDF確認ツール

このツールは、Windowsのダウンロードフォルダーに保存されたシフトPDFから、まだ確認していない未来分だけを一覧にします。

## 普段の使い方

1. LINEで新しいシフトPDFをダブルクリックして、ダウンロードフォルダーへ保存します。
2. `ローカルPDFからOutlookへ反映.bat` をダブルクリックします。
3. 初回だけ、PDFに記載される担当者の名字と反映先の予定表をPC上で設定します。
4. `PDFを開く` で原本を表示し、ローカルAIが作った予定一覧を確認します。
5. 正しい行だけにチェックを入れ、必要なら生徒名・教科・日時を修正します。
6. `Outlookへ反映` を押します。

この流れではCodexへPDFを送らず、Outlook Web版も使いません。

## 判定ルール

- `シフト表[...]`、`シフト表改訂[...]`、`守山北校シフト表[...]`など、既知のシフト表形式の名前だけが対象です。
- 請求書、教材、チラシなどの通常のPDFは無視します。
- 名前に「シフト」が含まれていても、既知の形式で始まらないPDFは無視します。
- ファイル名の `[7.27～8.1分]`、`[8.3～8分]`、`（7.6週）` などから対象期間を読み取ります。
- 対象期間の終了日が今日より前なら無視します。
- PDFの内容から識別値を作るため、同じPDFは再表示しません。
- 改訂版や内容が変更されたPDFは、新しい未確認PDFとして表示します。
- 同じ校舎・同じ期間のPDFが複数ある場合は、更新日時が最も新しいPDFだけを使います。
- 確認済みの記録は `.schedule-pdf-state.json` に保存します。
- 反映先は、初回に選択したデスクトップ版OutlookのローカルPSTだけです。
- 選択したPSTの保存先は `Schedule/private/local-schedule-config.json` に保存し、GitHubには含めません。
- Outlook Web版は更新しません。
- デスクトップ版Outlookへ反映するときは、現在時刻より前の予定を変更・削除しません。
- 今日のPDFに過去の時間帯が含まれていても、開始時刻を過ぎた予定は対象外です。
- Codexの自動確認は15分ごとに実行され、未確認PDFを最初に見つけたときに警告します。
- 同じ未確認PDFの警告は1日1回までです。新しい改訂版が増えた場合は、その時点で再度警告します。

## 安全上の動作

BATを開いただけではOutlookを変更しません。確認表は全件選択済みで開き、利用者が内容を確認して `Outlookへ反映` を押した未来の予定だけを追加・更新します。水口校の生徒名または教科名が空欄の行は、高解像度画像を使って端末内AIが再読取します。それでも空欄なら赤く表示し、反映前に確認を求めます。

## 個人情報の保護

- 生徒名を含むPDF、画像、抽出テキスト、JSON、CSV、PST、予定表書き出しファイルはGitHubへ保存しません。
- 読み取り用の一時ファイルは `tmp/pdfs/schoolie-shifts/` または `Schedule/private/` に置き、Gitの対象外にします。
- Gitへ保存するのは、個人名を含まないツール本体、説明書、一般化した反省記録だけです。
- `git add` の前に対象ファイル一覧を確認し、シフト原本・画像・抽出結果が含まれていないことを確認します。
- Outlookの本文に必要な生徒名はローカルPSTにだけ保存し、Web版Outlookへは反映しません。

### Codexで読み取る場合の注意

GitHubへ公開することと、CodexでPDFを処理することは別です。CodexにPDFの読み取りを依頼した場合、PDFの内容は処理のためOpenAIのサービスへ送られます。個人名をPCの外へ一切出さない運用が必要な場合は、Codexに原本を渡さず、ローカル専用の読み取り・Outlook反映処理へ切り替えます。

現在の標準は `ローカルPDFからOutlookへ反映.bat` です。PDFに埋め込まれた表データがある場合は、PC内で表のセルを直接読み取ります。表データがない場合だけ、Tesseract OCRとOllama上の `qwen2.5vl:7b` をPC内で実行します。通信先はローカルの `127.0.0.1` だけです。氏名入りの設定・解析結果・画像は `Schedule/private/` に保存され、GitHubの対象外です。

ローカルAIの読み間違いに備え、予定は必ず確認表を表示してから反映します。初期状態では全行が選択済みです。過去の予定と、確認表でチェックされていない予定は変更しません。水口校では色付きの授業セルだけを候補にし、生徒名・教科名・番号を自動読取します。複数生徒は「生徒名 教科 番号」を1人1行でOutlook本文へ保存します。守山北校は日時と時間帯だけを反映し、本文は空欄にします。未来のスクールIE予定には黄色カテゴリを設定します。
