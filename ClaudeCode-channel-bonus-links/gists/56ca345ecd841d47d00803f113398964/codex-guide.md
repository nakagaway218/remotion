## 1. Codexとは

OpenAIが提供する開発・業務向けのAIエージェント。CLI／IDE／ブラウザ／クラウド環境で動作し、コード生成・修正・レビューだけでなく、**コード以外の日常業務**（ドキュメント作成、調査、画像生成、ブラウザ操作など）も担う。

```
Codex（道具レイヤー）
  ├── 実行環境（CLI / IDE / Cloud / Browser）
  ├── プラグイン／スキル
  ├── サブエージェント
  └── GPT-5.5（頭脳レイヤー）
```

---

## 2. Claude Code との違い

| 観点 | Codex (GPT-5.5) | Claude Code (Opus 4.7) |
|---|---|---|
| **頭脳** | GPT-5.5 | Claude Opus 4.7 |
| **強み** | 修復力・安全設計・自動レビュー | 日本語力・長時間タスク・MCPエコシステム |
| **得意な場面** | 既存コードの破壊的変更を最小化したい / レビュー駆動 / 安全運用 | 大規模リファクタ / 日本語ドキュメント / MCP連携を多用 |
| **推奨** | 安定運用・本番修正 | 探索・設計・長時間自律タスク |

> **結論**: 両方を併用するのがベスト。タスクの性質で使い分ける。
> - 既存コードに手を入れる → Codex
> - 日本語の企画書・長時間の自律作業 → Claude Code

## 3. 最新アップデート（今週分）

### 3-1. Computer Use の大幅強化

- **速度が大幅向上**: 操作レイテンシが体感で数倍速く
- **スマートフォン操作に対応**: PC同様にスマホUIをCodexが直接操作可能
- **応用例**:
  - スマホアプリのUIテスト自動化
  - モバイルWebの動作検証
  - 営業・カスタマーサポートでのデモ自動化

### 3-2. `/pet` — Codex Pets

📎 公式: <https://developers.openai.com/codex/app/settings#codex-pets>

- **8種類のペット**から好きなキャラクターを選択
- 作業中のCodexの **状態を可視化**（思考中／実行中／待機中など）
- **待ち時間の不安を軽減** — 進捗が見えないストレスを解消
- **自分専用のペット**もカスタム作成可能

> **狙い**: 長時間タスクでの「ちゃんと動いてる？」という不安を、ペットの動作で直感的に解消するUX施策。

### 3-3. 開発領域の進化

#### Supabase 公式プラグイン

- データベース・認証・ストレージをCodexから直接操作
- スキーマ作成、RLS設定、関数デプロイをエージェント経由で自動化

#### Webサイト採点 Skill — codex-design-audit-skill

📎 リポジトリ: <https://github.com/Kappaemme-git/codex-design-audit-skill>

- 任意のWebサイトをCodexがデザイン観点で **自動採点**
- アクセシビリティ・UX・ビジュアル階層・タイポグラフィなどを評価
- リファクタや改善提案にそのまま使える

#### GPT-5.5 × Images 2.0 でアプリ開発

- 画像生成と推論を組み合わせ、**プロトタイプアプリを丸ごと生成**
- UIモックから実装まで一気通貫

### 3-4. コード以外の日常業務の進化

Codexは「開発者だけのツール」から「全職種のアシスタント」へ拡張：

| 機能 | できること |
|---|---|
| **職種別プラグイン提案** | 営業・マーケ・経理・法務など、職種を選ぶと最適なプラグイン群を自動推奨 |
| **専属アシスタント化** | あなたの業務パターンを学習し、定型作業を肩代わり |
| **進捗の常時可視化** | 何をどこまで進めているか、いつでも分かる |
| **下書き〜完成まで一貫対応** | アイデア出し → 構成 → ドラフト → 校正 → 公開、をシームレスに |

### 3-5. その他のアップデート

- **サブエージェント追加** — タスクを分担する子エージェントを呼び出し可能（Claude Codeと同様の構造）
- **HeyGenプラグイン追加** — AIアバター動画の生成・編集をCodexから実行（<https://t.co/7QYXx3GXaa>）
- **ネイティブブラウザ機能** — 外部ブラウザを起動せずにCodexが直接Web操作
- **「公式」Codex ユースケース集** が公開され、業務別のベストプラクティスが参照可能に

## 4. ユースケース別ガイド

### 4-1. エンジニア向け

- **既存コードの修正・リファクタ** — 修復力に強みあり、破壊的変更を最小化
- **コードレビュー自動化** — PR作成時に自動でレビューコメント生成
- **DBスキーマ設計** — Supabaseプラグインでフロー一気通貫
- **Webサイトのデザイン監査** — codex-design-audit-skillで定量評価

### 4-2. デザイナー / フロントエンド向け

- **GPT-5.5 × Images 2.0** でモック→実装のプロトタイピング
- **デザイン採点Skill** で既存サイトの改善箇所を抽出
- **HeyGen連携** でモーション付きのプロモ素材を生成

### 4-3. マーケター / コンテンツ制作者向け

- **下書き〜完成まで一貫支援** — ブログ・SNS・LPを通しで作成
- **HeyGenプラグイン** で動画コンテンツ量産
- **ブラウザネイティブ操作** で競合調査・トレンド収集

### 4-4. 営業 / カスタマーサクセス向け

- **Computer Use（スマホ対応）** でデモ自動化
- **職種別プラグイン提案** で営業特化のワークフロー構築
- **専属アシスタント** で議事録・フォローアップ自動化

### 4-5. バックオフィス（経理・法務・総務）向け

- 職種別プラグインで定型業務を委譲
- ドキュメント作成・確認の下書き〜完成支援
- 進捗可視化で複数案件の並行管理
