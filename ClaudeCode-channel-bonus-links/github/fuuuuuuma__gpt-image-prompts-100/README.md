# GPT Image 2.0 プロンプト100選

> X (Twitter) と note でバズった事例を中心に厳選した、**GPT Image 2.0** 向け実用プロンプト集です。
> そのままコピペして ChatGPT / API に貼るだけで使えます。日本語のまま渡してOK（英語版併記）。

## 使い方

1. 下のプロンプトをコピー
2. ChatGPT (GPT-5 / GPT-Image 2.0) または OpenAI API `gpt-image-2` モデルに渡す
3. `[ ]` で囲まれた部分を自分の素材・テーマに置き換える
4. 必要なら `--ar 1:1` `--ar 9:16` 等のアスペクト比を末尾に追加

> 💡 **コツ**: 参照画像を一緒に渡すと精度が劇的に上がります（人物・商品・ロゴなど）。

## 01. フィギュア化・3D化

X で爆発的に流行した「フィギュア化プロンプト」系。参照写真を1枚渡すのが必須。
