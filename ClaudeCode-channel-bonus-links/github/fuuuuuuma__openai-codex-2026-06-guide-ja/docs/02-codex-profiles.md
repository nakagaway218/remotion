# ② Codex プロフィールの刷新（Codex Profiles）

> Codex（OpenAI のコーディングエージェント）に「自分のホーム」ができました。使った量・連続日数・得意な機能をグラフで振り返り、見せたいときだけカードで共有できます。

確度マーク: ✅公式確認済み ／ 🔶一次情報はあるが流動的 ／ ⚠️未確認

---

## ひとことで言うと

「自分がどれくらい Codex を使い込んでいるか」を可視化するページです。GitHub の貢献グラフ（草）の Codex 版、とイメージすると近いです。✅

公式 changelog（2026-06-04）では「**Profile セクションにアクティビティの分析（activity insights）と共有カード（share cards）を追加**」と記載されています。✅

## 振り返れる項目

公式の app settings ドキュメントおよび @OpenAIDevs の投稿より ✅🔶:

- **アクティビティグラフ**（いつ・どれだけ使ったか）
- **ストリーク（連続利用日数）**
- **累計トークン（lifetime tokens）**
- **1日の最高トークン（peak daily tokens）**
- **最長タスク（longest task）**
- **よく使う機能**（例: plugins、/fast mode）

加えて、表示名・ユーザー名・アイコンといった**プロフィール情報の編集**もできます。✅

## プライバシー

最大のポイントは **「デフォルトで非公開」** であること。共有したいときだけ「カード」を渡す設計です（共有はコンシューマー向け ChatGPT プランで利用可能）。✅
勝手に公開されることはありません。

## 企業向けの見え方

Enterprise の分析では、ユーザーのランキング表（クレジット・スレッド・ターン・テキストトークン・現在のストリークなどで並べ替え・絞り込み）も用意されています。チーム全体の利用状況を管理者が把握する用途です。🔶

## このキットでの使いどころ

iOS アプリ制作を進めると、Codex の使用量（トークン・タスク）が積み上がります。プロフィールを開けば「どの機能をよく使ったか（例: /fast mode を多用した）」が分かり、**次の制作の進め方やコスト感の見直し**に使えます。🔶（運用ヒント）
