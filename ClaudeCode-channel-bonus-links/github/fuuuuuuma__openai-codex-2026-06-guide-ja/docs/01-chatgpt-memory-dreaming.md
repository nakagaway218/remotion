# ① ChatGPT の新メモリ「Dreaming（ドリーミング）」

> ChatGPT が、過去の会話をまたいで「あなたのこと」を覚え、時間の経過に合わせて記憶を自動で更新していく新しいメモリの仕組みです。
> 公式タイトルは "Dreaming: Better memory for a more helpful ChatGPT"。

確度マーク: ✅公式確認済み ／ 🔶一次情報はあるが流動的 ／ ⚠️未確認

---

## ひとことで言うと

これまでの ChatGPT のメモリは「覚えておいて」と頼んだことを保存する、いわば**メモ帳**でした。
Dreaming は、わざわざ頼まなくても**会話の中で自然に出てきた文脈を拾い、時間とともに古くなった情報を勝手に直してくれる**——いわば「あなたとの関係を続けていく相手」に近づける仕組みです。✅

具体例（公式）: 「7月にシンガポールへ行く」と話していた記憶を、旅行が終わった後に「**2026年7月にシンガポールへ行った**」へと自動で書き換えます。✅

## 何が新しいのか

- **会話をまたいで文脈を持ち越す**: 1つのスレッドの中だけでなく、複数の会話から学び、最新で関連性の高い文脈を次の会話に渡します。✅
- **「覚えて」と言わなくていい**: 明示的なリクエストに頼らず、自然に出てきた情報を記憶に取り込めます。✅
- **時間で記憶が更新される（dreaming）**: バックグラウンドのプロセスが、たくさんの会話からメモリの状態を合成し直し、常に新鮮な状態に保ちます。✅
- **無料ユーザーにも開放**: 計算コストを約5倍削減したことで、パーソナライズされたメモリ機能を**初めて無料アカウントにも**提供。🔶
- **有料は容量倍増**: Plus / Pro 向けにメモリ保存容量を倍に。🔶

## いつ・誰が使えるのか

- **提供開始**: 2026年6月4日、まず**米国の ChatGPT Plus / Pro** から。✅
- **拡大予定**: 数週間かけて他国、および **Free / Go** ユーザーへ広げる予定。✅
- バージョン名は二次情報で「**Dreaming V3**」と報じられています。🔶（公式ページのタイトルは "Dreaming"）

## プライバシー・コントロール

- 合成された記憶は「**メモリ要約ページ（memory summary page）**」で確認できます。✅
- そこから、ChatGPT が自分について把握している内容の要点を一覧で見て、**追加・更新**したり、「どの話題を・いつ持ち出すか」の指示を出したりできます。✅

> 使うときの考え方: 「正確に覚えていてほしいこと」「逆に覚えないでほしいこと」は、メモリ要約ページで自分でも見直せます。最初に一度ページを開いて、ChatGPT が持っている前提を確認しておくと安心です。

## この資料での扱い（なぜ載せているか）

この機能は **Codex（コーディング）とは別系統**の発表ですが、受け取ったあなたが「ChatGPT に長く付き合わせて、自分の好みや制約を踏まえた提案を受ける」使い方をするうえで土台になります。
このキットで iOS アプリを作るときも、ChatGPT 側に「自分はこういうアプリを、こういう方針で作りたい」と伝えておくと、Dreaming によって以降の相談が噛み合いやすくなります。🔶（運用上のヒントであり、公式の保証ではありません）
