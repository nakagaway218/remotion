なぜ Markdown だと AI に微妙なのか
AI 時代に Markdown が「微妙」になる理由

AI のアウトプットは量・複雑さが爆発している

  • → 仕様書が数百行になる
  • → 分析レポートに図・表が必要になる
  • → 登壇・提案で使えるクオリティが求められる

Markdown では対応できない

色も図もない長いテキストは誰も最後まで読まない。共有しても「開かない」まま埋もれる。

まとめると
Markdown の強みは
「人間が直接触れること」
——AI 時代にその前提が崩れた
だから HTML に変えるべき
