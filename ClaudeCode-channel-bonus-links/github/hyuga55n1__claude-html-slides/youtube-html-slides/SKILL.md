# YouTube HTML スライド生成スキル

YouTube解説動画に最適化した16:9 HTMLスライドを生成する。
ブランドカラーは都度ユーザーから受け取る。生成後にレビューエージェントで構成を検証し、必要に応じて修正する。

## 実行フロー

### Step 1: ヒアリング

以下を確認する（会話から判明していれば省略）:

```
1. 動画のテーマ（例: Claude Codeの使い方、HTMLで資料を作る方法）
2. 想定視聴者（例: 非エンジニア、中小企業経営者）
3. 動画でやってもらいたい1アクション（例: HTMLで出してみる、インストールする）
4. ブランドカラー（16進数で1〜3色、なければデフォルトを使用）
   デフォルト: メイン #3B82F6、サブ #60A5FA、テキスト #1F2937
5. 保存先パス（なければ current directory に slides.html）
```

### Step 2: 構成設計

`references/slide-structure.md` を読み、テーマに合ったスライド構成を設計する。
構成をユーザーに提示し、承認を得てから生成に進む。

フォーマット:
```
## スライド構成案（全XX枚）

| # | 種別 | タイトル | 目的 |
|---|------|----------|------|
| 1 | タイトル | ... | ... |
| 2 | フック | ... | ... |
...

この構成でよいですか？
```

### Step 3: HTML生成

承認後、`references/html-template.md` のCSS設計パターンを参照してHTMLを生成する。

**必須要件:**
- 16:9（aspect-ratio: 16/9）固定
- キーボード矢印キー・ボタン・ドットで画面送り
- Google Fonts: 見出し `Shippori Mincho B1`（serif）、本文 `Noto Sans JP`
- ブランドカラーを CSS 変数（`--c1`, `--c2`, `--text`）で管理
- 白背景ベース
- 全スライドで縦方向に余白が均等になるよう `justify-content: space-between` か `gap` で調整

**スライド種別ごとのルール:**
- `タイトル`: グラデーション背景（--c1 → --c2）、大きい明朝体見出し、装飾文字
- `パート見出し`: 白背景、大きい番号装飾（薄い色）、テーマ説明
- `コンテンツ`: カラーヘッダーバー + スライドタイトル + 本文エリア
- `まとめ`: 中央揃え、3カラムカード、締めのハイライトボックス

生成したHTMLを指定パスに保存する。

### Step 4: レビューエージェントによる構成チェック

HTMLを保存後、Agentを起動してスライド構成を検証する:

```
Agent({
  subagent_type: "general-purpose",
  prompt: `
以下のHTMLスライドファイルを読み、YouTube解説動画用の資料として構成品質をチェックしてください。

ファイル: {保存パス}

## チェック項目（各項目: Pass / Warn / Fail + 理由）

1. **フック** — 冒頭30秒で視聴者の悩み・欲求に刺さっているか
2. **1動画1アクション** — 動画を見終わったら何をするか1つに絞られているか
3. **前提→気づき→答え の流れ** — なぜその問題が起きるのか説明してから解決策を提示しているか
4. **スライド密度** — テキストが詰め込まれていないか（1スライド3〜5要素が目安）
5. **実演セクション** — 実際の手順・プロンプト例が含まれているか
6. **まとめ** — 視聴者が次に取るべき行動が明確か

## 出力フォーマット

### チェック結果
| 項目 | 判定 | コメント |
|------|------|--------|
...

### 総合判定
- **Go**: そのまま使用可
- **要修正**: 具体的な修正箇所を列挙

修正が必要な場合は、修正案も提示してください。
  `
})
```

### Step 5: 修正・完了

- **Go** → ファイルパスをユーザーに伝えて完了
- **要修正** → レビュー結果をユーザーに共有し、修正するかを確認してから対応
