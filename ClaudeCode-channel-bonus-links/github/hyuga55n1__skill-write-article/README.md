# skill-write-article

Claude Code スキル: AIツール・サービスの最新アップデート記事を**超初心者向け**に執筆する。

リサーチ → 執筆（15,000文字以上）→ スクリーンショット撮影 → 3人採点パネル（95点以上で通過）の全工程を自動化。

## インストール

`write-article.skill` をダウンロードして Claude Code にドラッグ&ドロップするだけ。

**[⬇ write-article.skill をダウンロード](https://github.com/hyuga55n1/skill-write-article/raw/main/write-article.skill)**

## 使い方

Claude Code で以下のように話しかけると起動します:

- 「〇〇の記事を書いて」
- 「Claude Codeの最新アップデートをまとめて記事にして」
- 「初心者でもわかる〇〇の解説記事を作って」
- `/write-article`

| ファイル | 内容 |
