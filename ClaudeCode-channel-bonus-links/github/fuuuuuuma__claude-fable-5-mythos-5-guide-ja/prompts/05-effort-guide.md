# 05 — effort の使い分けと「やりすぎ」の抑え方

Fable 5 は思考の深さを **effort**（low / medium / high / xhigh）で調整します。
公式指針: **普段は high が標準。最重要タスクだけ xhigh。ルーチンは medium / low。**
Fable 5 は低 effort でも旧モデルの xhigh を上回ることがあるため、
「時間がかかりすぎる」「もっとテンポよく対話したい」ときは下げるのが正解です。

## Claude Code での切替

```text
/effort
```

（モデルは /model claude-fable-5、1Mコンテキスト版は /model claude-fable-5[1m]）

## 高 effort の副作用「やりすぎ」を抑えるプロンプト

高 effort では、頼んでいない整理・リファクタ・将来用の抽象化を足しがちです。
気になったらこれを添えます:

```text
過剰な作り込みは避けてください。直接依頼したこと、明らかに必要なことだけ変更してください。
- 依頼範囲の外の機能追加・リファクタ・「ついで改善」はしない
- 1回しか使わない処理にヘルパーや抽象化を作らない
- 起こり得ないケースへの防御コードを足さない（検証は外部入力との境界だけ）
```

## 逆に「物足りない」とき

```text
想定ユースケースで実用になる範囲まで、しっかり作り込んでください。
着手前に不明点があれば質問してください。完成したら各機能を簡単に検証して報告してください。
```
