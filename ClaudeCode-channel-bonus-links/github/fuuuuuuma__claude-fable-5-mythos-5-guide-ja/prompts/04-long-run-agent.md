# 04 — 長時間の自律作業を任せる「3点セット」

Fable 5 の最大の持ち味は**長く複雑なタスクを自律で走り切る力**。
その力を安定して引き出す、公式ガイド由来のプロンプト3点セットです。
CLAUDE.md（雛形に組み込み済み）に書いておけば毎回効きます。

## ① 進捗報告のウソを防ぐ（公式テストで捏造報告がほぼ消えた指示）

```text
進捗を報告する前に、各主張をこのセッションのツール結果に照らして監査してください。
証拠を示せる作業だけ報告し、未検証のものは「未検証」と明示してください。
テストが失敗したら、その出力ごと正直に報告してください。
```

## ② コンテキスト残量で勝手に切り上げさせない

```text
コンテキストは十分残っています。残量を理由に停止・要約・新セッションの提案をせず、
作業を続けてください。
```

（長いセッションで「新しいセッションにしましょうか」「要約して引き継ぎます」と
言い出したときに送る。残量カウントダウン表示が引き金になりやすい）

## ③ 止まったときの再開

「やります」と言ったままツールを呼ばずターンが終わったら、ひとこと:

```text
continue
```

で再開します。最初から自律で走らせたいときは、依頼文の最後にこれを足します:

```text
あなたは自律で作業しています。元の依頼から導かれる、取り消し可能な作業は確認なしで
進めてください。完了するか、私にしか決められないことが出てきたときだけ止まってください。
```

## あわせて使うと強い: 学びの記録

```text
このタスクで得た教訓（ハマりどころ・確定した方針）を、理由つきで memory/lessons.md に
追記してください。1教訓1ブロック、冒頭に1行サマリで。
```
