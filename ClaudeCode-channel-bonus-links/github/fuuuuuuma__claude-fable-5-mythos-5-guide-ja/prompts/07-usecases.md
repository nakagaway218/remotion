「貼るだけ」事例集です。<> の中を自分の内容に置き換えて使ってください。

## コーディング

| 悩み | 貼るプロンプト |
|---|---|
| 大きめの機能を丸ごと任せたい | `<機能の説明>を実装してください。まず成功基準を3つ決めて提示し、実装→各基準の検証→結果報告まで一気に進めてください。途中で疑問が出たら先に質問してください。` |
| バグの原因がわからない | `<症状>を調査してください。推測で直さず、まず計測やログ追加で原因を特定し、修正後に「修正が効いた証拠」を見せてください。` |
| コードレビューしてほしい | `この変更をレビューしてください。スタイルより「実際に壊れるバグ」「セキュリティ」「設計の歪み」を優先し、確信度の高い指摘だけ、重要度順に出してください。` |
| 設計を相談したい | `<やりたいこと>の設計を相談させてください。前提は<前提>です。実現方法を3案、トレードオフ付きで比較して、おすすめを1つ選んでください。` |
