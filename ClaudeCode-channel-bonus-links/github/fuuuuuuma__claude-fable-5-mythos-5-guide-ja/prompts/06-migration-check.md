# 06 — 既存プロジェクトを Fable 5 に移行するチェック

Opus 4.8 などから Fable 5 に乗り換えるとき、**既存のプロンプト・スキルが古いまま**だと
かえって品質が下がることがあります（公式も「旧モデル向けのスキルは Fable 5 には
規定的すぎることが多い」と明言）。AIに移行チェックそのものを任せましょう。

## コピペするプロンプト

```text
このプロジェクトを Claude Fable 5 へ移行する準備チェックをしてください。
プロジェクト内のシステムプロンプト・CLAUDE.md・スキル・エージェント設定を読み、
次の観点で問題点と修正案を一覧にしてください。

1. 内部推論を書き出させる指示（reflection / show your thinking / 思考をそのまま出力等）
   → reasoning_extraction 分類器が作動し Opus 4.8 へのフォールバックが増えるため、
     要約・構造化出力への置き換え案を出す
2. 旧モデル向けの過剰な指示（「CRITICAL: 必ずこのツールを使え」等の強すぎる言い回し、
   細かすぎる手順の列挙）→ 短い指示への簡素化案を出す
3. extended thinking の budget_tokens 設定 → effort パラメータへの移行案を出す
4. 最後のアシスタントターンへの prefill → Structured Outputs 等への置き換え案を出す
5. タイムアウト設定 → 高 effort では1リクエスト数分・自律ランは数時間になり得る前提で
   見直し案を出す

修正はまだ実行せず、一覧と推奨順だけ出してください。
```

## 知っておくと安心な仕様（公式）

- Fable 5 のトークナイザは旧世代より**同じテキストで約30%多くトークンを生成**
  （コスト・上限の見積もりに影響）
- adaptive thinking が常時ON（`thinking: {"type": "disabled"}` は不可）
- データ保持: Fable 5 / Mythos 5 は全トラフィック30日保持（ゼロデータ保持の対象外）。
