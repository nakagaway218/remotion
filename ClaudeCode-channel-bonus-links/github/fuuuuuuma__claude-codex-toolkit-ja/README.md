## TL;DR（3行）

- Claude Code と Codex は「**スキル / コマンド / サブエージェント / フック / MCP**」という同じ5部品で拡張でき、それらを束ねて配るのが「**プラグイン（＋マーケットプレイス）**」。✅
- 外部サービス（GitHub・Notion・Slack・Figma など）に繋ぐ実体は **MCP サーバー**で、それを Claude のアプリ側で使いやすくラップしたものが「**コネクタ**」。土台はどちらも同じ Model Context Protocol。✅
- このリポジトリを丸ごとエージェントに渡せば、`AGENTS.md` を読んで「**おすすめ拡張の選定 → 設定ファイル生成 → 安全に利用**」までを補助できる。独自スキル・MCP の**自作テンプレ**も同梱。✅

## このリポジトリの使い方（3通り）

### 使い方A：AIエージェントに丸ごと渡す（推奨）

1. このリポジトリを `git clone` する（または ZIP でダウンロードして展開）。
2. Claude Code / Codex を**このフォルダの中で**起動する。
3. エージェントに次のように頼むだけ：

   > 「このリポジトリの `AGENTS.md` を読んで、私の用途（例：YouTube運用と動画編集の自動化）に合うプラグインとMCPを3つ提案して、設定ファイルまで作って」

エージェントは `AGENTS.md` → 必要な `docs/` の順に読み、`mcp/` や `config/` のサンプルを下敷きに設定を提案します。

### 使い方B：人間が辞書として読む

「Notionと繋ぎたい」「GitHubのMCPって何？」と思ったら、[docs/03-mcp-servers.md](docs/03-mcp-servers.md) や [docs/04-connectors.md](docs/04-connectors.md) を目次から引く使い方です。

### 使い方C：自分の拡張を足していく土台にする

[skills/_template/SKILL.md](skills/_template/SKILL.md) や [knowledge/](knowledge/) のテンプレを複製して、自分のスキル・MCPサーバーを `skills/` `knowledge/` に追加していけます。増やすほどエージェントが使える手数が増えます。

## まず押さえる「4つの言葉」（超要約）

詳しくは [docs/00-はじめに.md](docs/00-はじめに.md)。ここでは一言ずつ。

- **スキル（Skill）** … エージェントへの「手順書」。`SKILL.md` 1枚で、必要な時だけ読み込まれる。✅
- **プラグイン（Plugin）** … スキル・コマンド・フック・MCP設定などを**まとめて配る箱**。マーケットプレイスから入れる。✅
- **MCP サーバー（MCP server）** … 外部サービス（GitHub・Notion等）に繋ぐ**共通規格のアダプタ**。Model Context Protocol の実体。✅
- **コネクタ（Connector）** … Claude のアプリ（claude.ai / Desktop / Cowork）から、MCP サーバーを**ログインだけで使える形**にしたもの。✅

```
   スキル ─┐
 コマンド ─┤
サブエージェント ─┼─▶ プラグイン（束ねて配布）
   フック ─┤        ▲ マーケットプレイスで配る
MCP設定 ─┘        │
                    └ MCP サーバー ──▶ コネクタ（アプリで使う体験）
                       （Model Context Protocol が土台）
```
