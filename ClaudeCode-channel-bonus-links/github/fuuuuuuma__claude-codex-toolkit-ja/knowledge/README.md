# knowledge/ — 独自ノウハウ置き場

設定の勘所・自作ガイド・トラブル対処など、「手順書（スキル）」にしきれない**知識**をためる場所です。エージェントは必要な時にここを参照します。

## 収録ノウハウ

| ファイル | 中身 |
|---|---|
| [mcp自作ガイド.md](mcp自作ガイド.md) | 自社API・社内ツール用の **MCP サーバーを自作**する最小テンプレ（Python / TypeScript / .mcpb 配布） |
| [plugin自作ガイド.md](plugin自作ガイド.md) | スキル・MCP・フックを束ねて配る **プラグイン＋マーケットプレイス**の作り方（Claude Code / Codex） |

## 足していく使い方

作業の中で固まった知見（「このサービスのMCPはこう設定するとハマらない」「この手順が定番」など）は、`knowledge/<わかりやすい名前>.md` で足していってください。

- **手順を実行させたい**もの → スキルにする（[skills/](../skills/)）。
- **知識・勘所**を残したいもの → ここ（`knowledge/`）。

足したら、ルートの [README.md](../README.md) 目次に1行加えると次のエージェントが見つけやすくなります。

> このリポジトリは「育てる」前提です。最初は自作テンプレ2本だけですが、運用しながら自分の知見をためるほど、エージェントが使える手数が増えます。
