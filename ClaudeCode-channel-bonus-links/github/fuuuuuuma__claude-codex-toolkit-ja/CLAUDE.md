## このリポジトリでのあなたの動き方（要約）

1. [AGENTS.md](AGENTS.md) を読む（役割・読む順番・ルール）。
2. ユーザーの用途を確認し、[docs/](docs/) の必要な章だけ開く。
3. 拡張を選定し、[mcp/](mcp/)・[config/](config/) のサンプルを下敷きに設定を作る。
4. APIキー・トークンは必ずプレースホルダ／環境変数にする。
5. 未検証のサードパーティ拡張は [docs/06-セキュリティ.md](docs/06-セキュリティ.md) のチェックを通す。
