# プリセット: 企画・壁打ち

企画や提案の立案が多い人向け。「考える時間」を作業で奪われないための束。

## 入れるもの（推奨順）
1. **Brainstorming**（obra/superpowers）— アイデアを構造化。設計書承認までコードを書かない
2. **Grill Me**（mattpocock/skills）— 計画の考慮漏れを質問攻めで潰す
3. **Write a PRD**（mattpocock/skills、実repoは `to-prd`）— 会話から企画書を生成
4. （任意）**Design an Interface** — 設計案を3〜5個並列で比較

## まとめて回すなら
- 同梱の **企画壁打ちパック**（`skills/planning-sprint/`）が 1→2→3 を順に実行する一気通貫ワークフロー。
- 単体skillを入れてから planning-sprint を入れると、束ねて呼べる。

## 最初の1個だけなら
- **Grill Me**。手元の計画を渡すだけで穴が見える。導入コスト最小で効果が体感しやすい。
