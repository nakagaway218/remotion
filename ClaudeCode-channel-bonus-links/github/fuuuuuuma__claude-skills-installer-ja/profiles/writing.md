# プリセット: 文書・記事

提案書・記事・ブログなど「調べて書く」が多い人向け。

## 入れるもの（推奨順）
1. **Doc Co-Authoring**（anthropics/skills）— 情報収集→ドラフト→読者テストの3段階共同執筆
2. **Edit Article**（mattpocock/skills）— 情報依存グラフで再構成。文法ではなく構造の編集
3. （任意）**Content Researcher** — テーマからリサーチを構造化
4. （任意）**Claude SEO** — Web公開するなら検索最適化

## まとめて回すなら
- 同梱の **リサーチ→執筆パック**（`skills/research-to-writing/`）が Doc Co-Authoring→Edit Article を順に実行。
- 「調べて書いて直す」が一気通貫になる。

## 最初の1個だけなら
- **Doc Co-Authoring**。読者テスト（別セッションで分かりにくさを自動指摘）が単体でも効く。
