# プリセット: 資料作成

スライド・表・配布資料の作成が多い人向け。「見た目の統一」と「手作業の転記」を消す束。

## 入れるもの（推奨順）
1. **PPTX**（anthropics/skills）— 言葉でPowerPoint生成。スライド画像で確認可
2. **Theme Factory**（anthropics/skills）— 配色＋フォントを全ページ統一適用
3. **XLSX**（anthropics/skills）— 表・グラフ・数式自動化＋再計算検証
4. （任意）**PDF**（anthropics/skills）— 配布用PDFの結合・分割・抽出

## 組み合わせ方
- PPTX で作り、Theme Factory で見た目を一括統一すると、資料の体裁に時間を使わなくなる。
- 数表が多いなら XLSX を主役に。

## 最初の1個だけなら
- 毎回スライドを作るなら **PPTX**、表計算が中心なら **XLSX**。
