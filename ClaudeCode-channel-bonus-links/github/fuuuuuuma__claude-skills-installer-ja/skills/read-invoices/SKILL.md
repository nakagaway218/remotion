# Invoice Reader（請求書処理・要点版）

請求書PDFをフォルダに入れると、構造化されたCSVと計算検証レポートを生成します。
最重要の設計思想は「**計算はAI任せにしない**」こと。金額の整合は自動検証プログラムで厳密に確認します。

> このファイルは出典記事の説明から再構成した**要点版**です。
> 実運用では計算検証スクリプトとOCR連携を各自の環境に合わせて追加してください。

## 入力
- 請求書PDF（複数可）を1つのフォルダに入れる

## 処理方式（2段構え）
- テキストベースのPDF → Claude単体で読み取り
- 画像・スキャンされたPDF → OCR（例: Gemini）でテキスト化してから処理
  （OCRのAPIキーが無くても、テキストPDFだけなら処理できる）

## 計算検証（AIではなくプログラムで厳密に）
- 品目の合計 = 小計 が一致するか
- 小計 + 税 = 請求額 が一致するか
- 不整合があれば flagged に振り分ける

## 出力
- 構造化CSV（請求元・日付・品目・小計・税・請求額 など）
- 計算検証レポート
- 処理済みデータを `confirmed`（整合）と `flagged`（要確認）へ自動振り分け
  → 異常が出たものだけ手動で確認すればよい

## ポイント
- 転記ミスや計算不整合を自動検出
- 確認すべきは flagged だけ。作業をAIに渡し、判断に集中する
