# Meeting Automation（議事録自動化・要点版）

会議の録画やテキストを渡すと、議事録・TODO・次回アジェンダを生成します。
テキスト入力だけでも動くので、外部API契約なしで使い始められます。

> このファイルは出典記事の説明から再構成した**要点版**です。
> 実運用では下記テンプレート/連携を各自の環境に合わせて追加してください。

## 入力
- 会議の文字起こしテキスト（最小構成。これだけで動く）
- もしくは録画（tl;dv / Circleback MCP 等と連携して自動取得する場合）

## ワークフロー
1. 文字起こし（または録画から取得したテキスト）を受け取る
2. `team.md` があればメンバー情報を読み、話者の推定とTODO担当の割り当て精度を上げる
3. 議事録を生成（決定事項・論点・保留を分けて整理）
4. 発言からTODOを抽出し、担当者と期限を割り当てる
5. 次回アジェンダ（持ち越し・新規論点）を生成する

## 同梱を想定する補助ファイル（各自で用意）
- `templates/` … 議事録フォーマット、会議タイプ別テンプレート
- `team.md` … メンバー一覧（名前・役割）。話者推定とTODO割り当てに使用
- TODO抽出ルール（粒度・担当の決め方）

## ポイント
- テキストだけでも動く＝今日から試せる
- `team.md` を入れるほど話者推定とTODO割り当てが正確になる
- 議事録を書く時間は、本来は判断に使える時間
