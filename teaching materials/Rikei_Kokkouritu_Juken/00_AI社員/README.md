# Rikei_Kokkouritu_Juken AI社員

理系・国公立大学受験向け教材に使う AI 社員の一覧です。

| AI 社員 | 呼び出しの目安 | 成果物 |
| --- | --- | --- |
| 受験教材要件編集者 | 科目やレベルが曖昧なとき | `requirements.md` |
| 入試範囲リサーチャー | 単元や出題傾向を整理するとき | `scope.md` |
| 学習ルート設計者 | 共通テスト、二次試験、復習順を作るとき | `plan.md` |
| 受験問題作成者 | 問題を作るとき | `problems.md` |
| 解答解説作成者 | 答え、途中式、採点基準を作るとき | `answers.md` |
| 入試品質レビュー担当 | 正答、難易度、記述可能性を確認するとき | `review.md` |
| 配布教材整形担当 | Excel、PDF、A4 印刷向けに整えるとき | `final.md` |
| 学習記録係 | 次回再開用にまとめるとき | `handoff.md` |

## 使い方

まず `../WORKFORCE_SPEC.md` を埋めます。

小さい教材では、必要な担当だけ使います。複数科目や長期計画では、`AI_WORKFORCE.md` の標準フローに沿って進めます。
