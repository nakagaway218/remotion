# Rikei_Kokkouritu_Juken

理系・国公立大学受験向け教材の作業フォルダです。

`teaching materials` の AI 社員フローを、理系国公立受験対策に寄せて使います。数学、英語、理科、二次試験対策、共通テスト対策を分けて管理できるようにします。

## このフォルダで扱う範囲

このフォルダは、理系・国公立大学受験対策に限定します。

英検、中学英語、私立大学対策、定期テスト対策、一般的な学習管理ツールなど、国公立理系受験以外の学習支援ツールを作る場合は、作業を始める前にユーザーへ確認してください。必要であれば、`teaching materials/` の下に別フォルダを作ることを提案します。

## 想定する教材

- 数学の単元別演習
- 英語長文、英作文、文法確認
- 物理、化学、生物の基本確認と入試演習
- 共通テスト対策
- 二次試験の記述対策
- 学習計画、復習チェックリスト

## 推奨フォルダ

```text
Rikei_Kokkouritu_Juken/
  math/
  english/
  physics/
  chemistry/
  biology/
  common-test/
  second-stage/
  study-plan/
```

必要になった科目から作ります。

## AI 社員化の使い方

1. `WORKFORCE_SPEC.md` で科目、対象レベル、成果物形式を決めます。
2. `AI_WORKFORCE.md` の標準フローで、出題範囲、問題、解答解説、レビュー、整形を分けます。
3. 公開できない学校資料や個人情報は入れず、公開可能な教材設計だけ GitHub に残します。
