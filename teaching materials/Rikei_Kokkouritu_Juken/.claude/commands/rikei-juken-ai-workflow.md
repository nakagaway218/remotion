# /rikei-juken-ai-workflow [受験教材テーマ]

`AI_WORKFORCE.md` と `WORKFORCE_SPEC.md` を読み、`[受験教材テーマ]` を Rikei_Kokkouritu_Juken の AI 社員フローに分解してください。

## 手順

1. 受験教材要件編集者として、科目、単元、試験区分、目標レベル、成果物形式を整理する。
2. 入試範囲リサーチャーとして、出題範囲、既存資料、未確認事項を列挙する。
3. 学習ルート設計者として、共通テスト、二次試験、復習順、演習量を分ける。
4. 受験問題作成者として、基本、標準、発展、記述問題の作成範囲を整理する。
5. 解答解説作成者として、答え、途中式、採点基準、別解、誤答例を整理する。
6. 入試品質レビュー担当として、正答、難易度、単元整合、著作権、個人情報リスクを確認する。
7. 配布教材整形担当として、最終形式を決める。
8. 学習記録係として、保存先と引き継ぎファイルを提案する。
