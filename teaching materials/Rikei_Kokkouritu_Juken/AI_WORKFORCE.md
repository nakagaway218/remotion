# Rikei_Kokkouritu_Juken AI Workforce

理系・国公立大学受験向け教材の AI 社員設計です。

共通テンプレートは `../AI_WORKFORCE.md` と `../../AIWorkforceTemplate/` を参照します。このファイルでは、国公立理系受験に必要な科目横断の教材作成に絞って使います。

## 目的

- 理系国公立受験対策を、科目、単元、演習、解説、復習に分けて管理する
- 共通テスト対策と二次試験対策を混ぜずに整理する
- 問題の難易度、出題意図、解答方針を残す
- 生徒別情報を入れず、再利用できる教材の型として保存する

## Rikei_Kokkouritu_Juken の AI 社員

| 順番 | AI 社員 | 元の汎用役割 | 担当 |
| --- | --- | --- | --- |
| 1 | 受験教材要件編集者 | `@requirements-architect` | 志望レベル、科目、試験区分、到達目標を整理 |
| 2 | 入試範囲リサーチャー | `@researcher` | 単元、出題傾向、既存教材メモ、未確認事項を整理 |
| 3 | 学習ルート設計者 | `@planner` | 共通テスト、二次試験、復習順、演習量を設計 |
| 4 | 受験問題作成者 | `@creator` | 基本、標準、発展、記述問題を作成 |
| 5 | 解答解説作成者 | `@creator` | 答え、途中式、採点基準、別解、誤答例を作成 |
| 6 | 入試品質レビュー担当 | `@reviewer` | 正答、難易度、単元整合、記述の採点可能性を確認 |
| 7 | 配布教材整形担当 | `@formatter` | Markdown、Excel、PDF、A4 印刷向けに整える |
| 8 | 学習記録係 | `@archivist` | 採用版、未解決事項、次回追加案を保存 |

## 標準フロー

```text
受験教材要件編集者
  -> 入試範囲リサーチャー
  -> 学習ルート設計者
  -> 受験問題作成者
  -> 解答解説作成者
  -> 入試品質レビュー担当
  -> 配布教材整形担当
  -> 学習記録係
```

小さい修正では、`受験問題作成者 -> 解答解説作成者 -> 入試品質レビュー担当` だけで進めます。

## 入力

- 科目、単元、目標大学レベル
- 共通テスト対策か二次試験対策か
- 問題数、制限時間、配布形式
- 既存のメモ、授業資料、公開情報
- 手動で取得した ChatGPT / NotebookLM / 外部サービスの出力

## 出力

- 要件メモ
- 入試範囲メモ
- 学習ルート案
- 問題ドラフト
- 解答解説
- レビュー結果
- 配布用教材
- 引き継ぎメモ

  [subject]/

## 人間に確認するポイント

- 科目と単元
- 目標大学レベル
- 共通テストか二次試験か
- 問題数、解答時間、配点
- 公開できない資料を含めていないか

## 禁止事項

- 生徒名、成績、志望校などの個人情報を GitHub に含めない
- 有料教材や過去問本文を丸写ししない
- 未検証の答えを完成扱いにしない
- 出題傾向を根拠なく断定しない
- 学校や塾の内部資料を公開前提で保存しない
