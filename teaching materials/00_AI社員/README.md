# Teaching Materials AI社員

教材作成に使う AI 社員の一覧です。

| AI 社員 | 呼び出しの目安 | 成果物 |
| --- | --- | --- |
| 教材要件編集者 | 対象や難易度が曖昧なとき | `requirements.md` |
| 出題範囲リサーチャー | 単元や入試傾向を整理するとき | `scope.md` |
| カリキュラム設計者 | 問題の順番や授業導線を作るとき | `curriculum.md` |
| 問題作成者 | 例題や演習問題を作るとき | `problems.md` |
| 解答解説作成者 | 答え、途中式、別解を作るとき | `answers.md` |
| 教材レビュー担当 | 正答、難易度、公開リスクを確認するとき | `review.md` |
| 印刷・配布整形担当 | Excel、PDF、A4 印刷向けに整えるとき | `final.md` |
| 教材記録係 | 次回再開用にまとめるとき | `handoff.md` |

## 使い方

まず `../WORKFORCE_SPEC.md` を埋めます。

小さい教材では、必要な担当だけ使います。受験対策や複数回分の教材では、`AI_WORKFORCE.md` の標準フローに沿って進めます。
