# 記事テンプレート

記事タイプを選び、対応する型で書く。完成後 note へ貼り付け。

---
## メタ情報（執筆前に埋める）
- 記事タイプ：無料(SEO集客) / 有料(単発) / メンバーシップ向け
- 狙うキーワード：
- 想定読者：
- 想定文字数：
- CTA（導線先）：関連記事 / 有料記事 / メンバーシップ

---
## ① 無料記事（SEO集客）型
```
# [キーワードを前方に入れたタイトル]

（冒頭3行：誰の・何の悩みを・どう解決するか。結論を予告）

## [読者の問い1]
（答え→具体例/根拠）

## [読者の問い2]
（答え→具体例/根拠）

## [読者の問い3]
（答え→具体例/根拠）

## まとめ
（要点の再整理）

---
（CTA：もっと知りたい人へ → 有料記事/メンバーシップへ自然に誘導）
```

## ② 有料記事（単発）型
```
# [ベネフィット＋具体性のあるタイトル]

（無料リード：価値を証明し、山場の手前まで。「この続きが欲しい」で止める）

【ここから有料】

## [具体手順/テンプレ/実例/数字]
（無料の焼き直しではない、固有の価値）

## [さらに踏み込んだノウハウ]

## まとめ＋次の一歩
```

## ③ メンバーシップ向け（連載）型
```
# [連載名 第N回] サブタイトル

（前回の振り返り→今回の学び）

## 本編
（限定性・最新性・シリーズ性を持たせる）

## 次回予告
（続きが気になる引き）
```

## note貼り付け時の注意
- noteエディタは Markdown の「##」見出しを**自動変換しない**。貼り付け後に、見出し行を選択して「大見出し/中見出し」を手動指定する。
- 箇条書き（・）やチェックリストも、必要に応じてnoteのリスト書式に直す。
- 画像は権利が明確なもの（自作/フリー素材/note公式）を使う。
