# note収益化 AIチーム 運用ガイド

このチームを使って、noteの発信〜マネタイズを回すための手引きです。

## マネタイズの考え方
1. **無料記事でSEO流入を増やす**（数を打って入口を広げる）
2. 読者を **有料記事（単発）** と **メンバーシップ（月額サブスク）** に転換してストック収益化
3. 比率の目安：無料3〜4本 : 有料1本

> ⚠️ note投稿・有料設定・決済・規約最終判断・実績報告は **必ずあなた本人** が行います。
> AI社員は完成原稿・設計の提示まで。実績・数値の捏造は禁止。

## チーム（7役）
| ロール | エージェント | 役割 |
|---|---|---|
| 編集長/ディレクター | `note-director` | ジャンル発注・KPI・指示出し・公開GO |
| 市場リサーチャー | `note-researcher` | ジャンル選定・キーワード・競合分析・ファクト |
| 編集設計(構成) | `note-planner` | タイトル・見出し・有料ライン設計 |
| ライター | `note-writer` | 本文執筆・トンマナ切替 |
| 校閲/コンプラ | `note-editor` | 誤字・法規制・著作権・note規約チェック |
| グロース/SEO | `note-growth` | タイトルAB・タグ・公開時間・回遊・分析 |
| マネタイズ設計 | `note-monetizer` | 有料化判断・価格・メンバーシップ特典設計 |

※最小構成は前5役。growth と monetizer は軌道に乗ってから。

## ワークフロー
```
Phase 0 ジャンル選定    director → researcher
Phase 1 ネタ/KW設計     researcher → planner
Phase 2 記事制作        planner → writer → editor
Phase 3 公開・最適化     growth（投稿はあなた）
Phase 4 マネタイズ      monetizer（決済はあなた）
Phase 5 分析・改善       growth → director（週次）
```

## 週次サイクル
- **月**：仕込み。director→researcher で今週のテーマ5本＋キーワード確定
- **火〜木**：量産。planner→writer→editor を1日1〜2本（無料3:有料1）
- **金**：公開。あなたが note に投稿（growthの公開設定メモを添付）
- **土**：分析。growth が数値診断 → director が翌週方針

## 使い方（起動方法）
1. note運用をするフォルダで Claude Code を開く
2. `/note-team` と打つ（または「noteを回して」「新ジャンル立ち上げて」）
3. 司令塔が作業フォルダ `note-team/` を用意し、各員を順に動かす
4. 校閲＋規約チェックを通った完成原稿＋公開設定メモが出たら **あなたが投稿**

## 作業フォルダ
```
note-team/
  テンプレ/      記事テンプレ・ジャンル選定シート
  ナレッジ/      勝ちパターン・フレームワーク／競合リサーチSOP／自分で作る競合データ
  ジャンル/      ジャンル選定リサーチ・キーワード台帳
  記事/          ネタ→構成→初稿→校閲→完成原稿
  分析/          週次ダッシュボード・改善ログ
```

## はじめての一歩（おすすめ）
1. `/note-team` を実行 → director にジャンル選定を発注
2. researcher が `競合リサーチSOP_noteAPI.md` の手順で、自分のジャンルの勝ち記事を10本分析
3. その型を `勝ちパターン_フレームワーク.md` に追記
4. 無料記事を1本、planner→writer→editor で作る
5. growth に公開設定メモを作らせ、あなたが投稿
6. 数本たまったら有料記事＋メンバーシップを monetizer に設計させる
