# note収益化 AIチーム キット（Claude Code 配布版）

noteの**ジャンルリサーチ〜記事制作〜公開最適化〜マネタイズ〜分析**を、
7役の「AI社員チーム」で回すための Claude Code 用キットです。

- **無料記事でSEO集客** → **有料記事（単発）＋メンバーシップ（月額）** で収益化する運用を、ひとり〜少人数で内製化できます。
- 司令塔スキル（`note-team`）を呼ぶと、7体のサブエージェントを正しい順番で動かします。
- ジャンルは固定していません。チームのリサーチャーがあなたの選んだジャンルに合わせて運用します。

> このキットには、配布者の個人情報・アカウント・固有データは一切含まれていません。
> すべてのテンプレ・ナレッジは「型（フレームワーク）」と「手順」だけで構成されています。

---

## これは何でできているか

| 種類 | 名前 | 役割 |
|---|---|---|
| スキル（司令塔） | `note-team` | 7役を順番に起動して1サイクル回す |
| エージェント | `note-director` | 編集長。ジャンル発注・KPI・指示出し・公開GO判断 |
| エージェント | `note-researcher` | ジャンル選定・キーワード・競合分析・ファクト |
| エージェント | `note-planner` | タイトル・見出し構成・有料ライン設計 |
| エージェント | `note-writer` | 本文執筆・トンマナ切替 |
| エージェント | `note-editor` | 校閲・法規制・著作権・note規約チェック |
| エージェント | `note-growth` | タイトルAB・タグ・公開時間・回遊・数値分析 |
| エージェント | `note-monetizer` | 有料化判断・価格・メンバーシップ設計 |

最小構成は前5役（director / researcher / planner / writer / editor）。growth と monetizer は軌道に乗ってから使えばOKです。

## インストール方法（どちらか）

### 方法A：プラグインとして入れる（おすすめ）

このキットはプラグイン構造（`note-money-team/`）になっています。

1. `note-money-team/` フォルダを、自分のマシンの分かる場所に置く。
2. Claude Code で、ローカルのプラグインとして読み込む。
   - マーケットプレイス経由で配る場合は、配布者の手順に従ってください。
   - 手元で使うだけなら、下の「方法B（手動コピー）」が確実です。

### 方法B：手動コピー（プラグインの仕組みを使わない・確実）

`note-money-team/` の中身を、自分の Claude Code 設定にコピーします。

```
# 1) 7体のエージェントをコピー（ユーザー全体で使う場合）
cp note-money-team/agents/*.md  ~/.claude/agents/

# 2) 司令塔スキルをコピー
cp -R note-money-team/skills/note-team  ~/.claude/skills/note-team
```

特定のプロジェクトだけで使いたい場合は、コピー先を
`~/.claude/` の代わりにプロジェクト直下の `.claude/` にしてください。

> Windowsの場合は `~/.claude` を `%USERPROFILE%\.claude` に読み替え、`cp` をエクスプローラーのコピー＆ペーストで行ってください。

## 使い方（3ステップ）

1. note運用をしたいフォルダ（プロジェクト）で Claude Code を開く。
2. `/note-team` と打つ（または「noteを回して」「新ジャンル立ち上げて」と頼む）。
3. 司令塔が初回だけ作業フォルダ `note-team/` を作り、あとは各役を順番に動かします。
   完成原稿＋公開設定メモが出てきたら、**あなた自身が note に投稿**してください。

---

## 大事なルール（安全のため）

- **note投稿・有料設定・決済・規約の最終判断・実績報告は、必ずあなた本人が行います。**
  AIチームは「完成原稿」「公開設定メモ」「価格・特典の設計案」を出すところまでです。
- **実績・数値の捏造は禁止**。分析は実データに基づき、無いものは「データ待ち」と明記します。
- note規約（過度な外部誘導・情報商材的販売・アフィリ制限）を尊重します。グレーな施策は強行せず、あなたの判断に委ねます。
- 競合記事は**構造の分析のみ**で、文章のコピーはしません（著作権）。
