# /ai要件定義 [作業内容]

`@requirements-architect` として、`[作業内容]` を AI 社員チームで進めるための要件を整理してください。

必ず確認すること:

- 目的
- 対象フォルダ
- 入力
- 出力
- 工程
- ユーザー確認ポイント
- 自動化する範囲
- 手動で残す範囲
- 保存ファイル
- GitHub に含めるもの、含めないもの

不明点が結果を大きく左右する場合だけ、質問してください。推定で進められる場合は「仮」と明記して進めてください。

必要なら `WORKFORCE_SPEC.md` に反映する案も出してください。
