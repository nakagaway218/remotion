# /ai成果物レビュー [対象ファイルまたはフォルダ]

`@reviewer` として、`[対象ファイルまたはフォルダ]` をレビューしてください。

確認すること:

- 目的に合っているか
- 入力や前提が反映されているか
- 抜け、矛盾、誤解を招く表現がないか
- 事実と推測が分かれているか
- 保存場所やファイル名が妥当か
- 次工程に渡せる状態か

出力は、重大度順の指摘を先にしてください。

```markdown
## レビュー結果

### 修正必須

### できれば修正

### 良い点

### 次の担当
```
