# Learning Tool 使い方

このファイルはPC利用者向けREADMEの雛形です。

## 開くファイル

`Template_Start.cmd` をダブルクリックしてください。

## 基本の流れ

1. 使用するAIを選びます。
2. 学習内容を入力します。
3. `質問文を作成` を押します。
4. 作成された文面をコピーして、選んだAIのチャット画面に貼り付けます。
5. 必要に応じてAIの回答をツールへ貼り戻します。
6. 追加依頼や次の学習へ進みます。

## 注意

- 通常利用ではAPIキーは不要です。
- zipは展開してから使ってください。
- うまく開かない場合はChromeで試してください。
