# Learning Tool スマホ版 使い方

このファイルはスマホ利用者向けREADMEの雛形です。

## 開くファイル

スマホでは、次のファイルをブラウザーで開いてください。

```text
Template_Mobile.html
```

Windows用の `.cmd` ファイルはスマホでは使いません。

## 基本の流れ

1. 使用するAIを選びます。
2. 学習内容を入力します。
3. 作成された文面をコピーします。
4. 選んだAIのチャット画面に貼り付けます。
5. 必要に応じて追加依頼を作成します。

## 注意

- スマホでは標準キーボードのマイク入力を使う方が安定する場合があります。
- zipを展開してから使ってください。
- うまく開けない場合はChromeで試してください。
