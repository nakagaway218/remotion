# Learner 使い方

高校生向け学習QAを、ChatGPT / Claude / Gemini に貼り付けて使いやすくするためのツールです。

## まず開くファイル

`C_Learner_Start.cmd` をダブルクリックしてください。

ブラウザーで学習QA操作画面が開きます。

## 基本の流れ

1. 使うAIを選びます。
2. 科目を選びます。
3. 質問を直接入力、または画像読み取りを選びます。
4. 質問文を入力します。
5. `質問文を作成` を押します。
6. 作成された文面をコピーして、選んだAIのチャット画面に貼り付けます。
7. AIの回答をこのツールに貼り戻します。
8. 必要に応じて、別解や詳しい解説などを追加で依頼します。
9. 終わるときは `[終了]` を押します。

## 音声入力

Chromeで開くと、質問文を音声入力できます。

初回はマイクの使用許可が出ることがあります。許可してください。

## 画像読み取り

画像そのものの読み取りは、ChatGPT / Claude / Gemini 側で行います。

このツールは、画像をAIに送るときの操作文を作る補助をします。

## API連携について

通常利用ではAPIキーは不要です。

`ChatGPT APIで直接質問` は、今後API連携を使う場合の予備機能です。
APIを使う場合は従量課金になることがあります。

## うまく開かない場合

- Google Chromeで開いてください。
- zipを展開してから使ってください。
- `C_Learner_Start.cmd` と `C_Learner_Index.html` は同じフォルダに置いてください。
