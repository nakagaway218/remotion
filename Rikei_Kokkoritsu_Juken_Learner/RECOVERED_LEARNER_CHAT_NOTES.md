# Learner チャット復元メモ

作成日: 2026-06-13

このメモは、Codex / Learner 関連チャットが見えなくなった場合に、過去ログと現在のプロジェクト文脈から復元できる決定事項をまとめたものです。

## 現在の結論

- Learner アプリ内の右側「履歴」は、ブラウザを閉じたりページを更新したりすると消える一時的な履歴です。
- 現在の `C_Learner_Index.html` / `C_Learner_Mobile.html` では、履歴は `state.history` にだけ保持され、`localStorage` などの永続保存は使っていません。
- そのため、Learner アプリ内履歴そのものを後から完全復元することは難しいです。
- 一方で、Codex 側の過去作業ログやメモリーから、Learner の仕様・決定事項・注意点は復元できます。

## Learner の基本方針

- Learner は、国公立理系受験向けの学習質問補助ツールです。
- メイン入口は `C_Learner_Start.cmd` です。
- 通常利用は、HTML を直接開いて ChatGPT / Claude / Gemini に手動でプロンプトを渡す方式です。
- `01_START_LEARNER.cmd` と `C_Learner_Server.cjs` は、OpenAI API を使うサーバー/APIモード用です。
- APIモードは補助的な位置づけで、手動コピー方式を置き換える前提ではありません。
- UIは複雑な資料連携よりも、安定して最後まで使えることを優先します。

## 消えたチャットから復元できる主な決定事項

### 1. 科目ごとのプロンプト方針

- 数学・理科では、答えだけでなく、考え方、公式、途中式、なぜその方法を選ぶかを説明させます。
- 数学・理科では、説明とは別に答案として使える `模範解答` セクションを入れる方針です。
- 英語・古文・漢文に、数学・理科向けの文言を混ぜてはいけません。
- 以前、英語の質問に `数III・理科の発展問題` や `模範解答` のような理系向け文言が混ざったため、科目別に回答方針を分けることになりました。

### 2. 基本確認資料は自動挿入しない

以下の資料は、現在の通常フローでは自動でプロンプトに入れない方針です。

- 三角比
- 英語助動詞
- 日本語助動詞

理由:

- 関係ない科目や質問に混ざると、プロンプトが長くなり、回答がぶれやすくなります。
- ユーザー判断として「今後出さないほうがよい」と整理されました。
- 復活させる場合も、直接 Excel / PowerPoint を開く方式ではなく、短く整理した Markdown メモを必要な科目だけに渡す形が安全です。

### 3. 参考資料連携の失敗から得た方針

- HTML から Excel / PowerPoint を直接開かせる方式は、Windows のファイル起動やブラウザ制約で不安定になりやすいです。
- 参考資料を使うなら、教材を Markdown に整理して、プロンプトに必要部分だけを入れるほうが安全です。
- Obsidian は思考・資料整理、Notion は管理表、GitHub は Codex が読む完成済み資料、という分担が安定方針です。
- Obsidian Vault は `C:\Users\nakag\Documents\Obsidian Vault\` に置いて問題ありません。
- デスクトップには実体フォルダーではなく、ショートカットだけを置くのが望ましいです。

## 今後の作業で守ること

- 変更前に `git status --porcelain=v1 -uall` で作業ツリーを確認します。
- PC版とスマホ版の挙動を揃えます。
- `buildApiQuestion()` や回答方針を変更するときは、科目別の分岐を崩さないようにします。
- 英語・古文・漢文に数学・理科の説明文を混ぜないようにします。
- 三角比 / 英語助動詞 / 日本語助動詞の資料は、ユーザーが明示的に希望したときだけ復活させます。
- 復活させる場合も、直接 Office ファイルを開く方式ではなく、Markdown 化した短い資料を使います。

## チャット消失への対策案

今後、同じ問題を減らすには次のどちらかが現実的です。

1. 重要な決定事項は、このファイルや `AI_CONTEXT.md` に追記する。
2. Learner アプリ内の履歴を `localStorage` に保存する機能を追加する。

`localStorage` は、ブラウザ内に小さなデータを保存する仕組みです。これを使うと、ページを閉じても履歴を残せます。ただし、共有PCや個人情報を含む質問では注意が必要です。

## 復元できた過去チャットの要点

- Learner は手動プロンプト転送を中心にする。
- APIモードは補助であり、主導線にしない。
- 数学・理科は、解説と模範解答を分ける。
- 英語・古文・漢文は、それぞれの科目に合う説明にする。
- 科目に合わない理系文言を混ぜない。
- 基本確認資料は自動挿入しない。
- 参考資料を使う場合は Markdown 化し、必要な場面にだけ渡す。
- Obsidian / Notion / GitHub の役割を分ける。
- GitHub には Codex が読む完成済み・管理対象のファイルを置く。
