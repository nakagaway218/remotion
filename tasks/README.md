# Tasks

This folder holds task-level handoff notes that can be shared between ChatGPT/Codex, Claude Code, Antigravity, and future assistants.

Use this folder when a task needs durable state outside chat history.

## Folders

- `active/` - tasks currently being worked on or expected to resume soon.
- `paused/` - interrupted, blocked, or waiting tasks.
- `done/` - completed task notes that are useful to keep.

## Minimal Task Format

```markdown
# Task: <short title>

## Objective

## Current State

## Completed

## Remaining

## Known Issues / Risks

## Next Step

## Last Updated
YYYY-MM-DD
```

Keep task files factual. If a status is uncertain, say so directly instead of guessing.
