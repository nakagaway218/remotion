# Career AI Project Workforce Spec

教育、AI活用、キャリア仮説に関する作業を始める前の小さな要件定義です。

## 目的

- 何を整理または検証するための作業か:
- 完了後に判断できるようになること:

## 前提確認

- 元情報に商業的誘導の可能性はあるか:
- 事実として確認できること:
- 仮説として扱うこと:
- まだ判断しないこと:

## 対象

- 対象テーマ:
  - [ ] キャリア仮説
  - [ ] AI副業という表現の妥当性
  - [ ] 教育AI活用支援
  - [ ] 教材開発
  - [ ] AI研修
  - [ ] NotebookLM活用
  - [ ] ChatGPT / Claude / Gemini の費用対効果
  - [ ] 情報商材・講座系提案のバイアス点検
  - [ ] その他:
- 対象ファイル:
- GitHubに公開してよい範囲:

## 入力

- ユーザーが入力するもの:
- 読み込むファイル:
- 外部サービスから取得するもの:
- 必須:
- 任意:

## 出力

- 画面に表示するもの:
- 保存するもの:
- ファイル形式:
- GitHub に含めるもの:
- GitHub に含めないもの:

## 工程

1. 目的整理:
2. バイアス点検:
3. 公開可否チェック:
4. 調査:
5. 仮説設計:
6. 小さな試作品作成:
7. 教育成果と費用対効果のレビュー:
8. 中立表現への整形:
9. 検証結果と次回行動の記録:

## ユーザー確認ポイント

- 作業前に確認すること:
- 中間で確認すること:
- 最後に確認すること:

## 品質チェック

- 事実、仮説、宣伝文句が分かれているか:
- 教育成果につながる内容か:
- 個人情報や非公開案件情報が含まれていないか:
- AIツール導入や講座購入が目的化していないか:
- 無料または低コストで検証できる手順があるか:
- 次の作業に再利用できる形か:

- [ ] 教育AI調査担当

- [ ] 中立表現整形担当
- [ ] 検証記録担当
