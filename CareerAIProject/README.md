# CareerAIProject

教育、AI活用、キャリア仮説、事業案を中立的に整理するためのコンテキスト置き場です。

元になったGPTsの分析には、情報商材会社や講座販売への誘導が含まれている可能性があります。そのため、このフォルダの内容は「確定診断」ではなく「検証するための作業仮説」として扱います。

## まず読むファイル

| ファイル | 用途 |
| --- | --- |
| `CONTEXT.md` | 中立化したプロフィール、キャリア仮説、AI活用方針 |
| `BIAS_REVIEW.md` | 情報商材的なバイアスを点検するための基準 |
| `AI_WORKFORCE.md` | 中立的に検証するためのAI社員設計 |
| `WORKFORCE_SPEC.md` | 作業前の小さな要件定義 |
| `chat_logs/` | GPTs など外部AIとの会話ログ。結論ではなく一次資料として扱う |

## 使い方

Codex や Claude Code に相談するときは、次のように依頼します。

```text
まず CareerAIProject/CONTEXT.md と CareerAIProject/BIAS_REVIEW.md を読んでください。
この内容を確定診断ではなく、検証前の作業仮説として扱ってください。
その前提で、教育・AI活用・キャリア設計について中立的に整理してください。
```

## 保存してよいもの

- 公開してよいキャリア仮説
- 教育AI活用の検証計画
- 教材開発や研修の汎用プロンプト
- 個人情報を除いた成功事例
- AIツールの費用対効果メモ
- 外部AIや講座系提案のバイアス点検結果

## 保存しないもの

- 実名の生徒情報
- 学校名、顧客名、案件固有情報
- 非公開の成績、添削内容、相談内容
- APIキーやログイン情報
- 情報商材や講座の宣伝文句をそのまま採用した文章
