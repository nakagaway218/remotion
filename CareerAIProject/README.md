# CareerAIProject

教育AIストラテジストとしてのキャリア戦略、AI活用、事業設計、AI社員化のためのコンテキスト置き場です。

## まず読むファイル

| ファイル | 用途 |
| --- | --- |
| `CONTEXT.md` | 固定プロフィール、強み、キャリア仮説、AI副業戦略 |
| `AI_WORKFORCE.md` | キャリア・教育AI領域をAI社員化するための役割設計 |
| `WORKFORCE_SPEC.md` | 作業前の小さな要件定義 |
| `chat_logs/` | GPTs など外部AIとの会話ログ、要点メモ |

## 使い方

Codex や Claude Code に相談するときは、次のように依頼します。

```text
まず CareerAIProject/CONTEXT.md を読んでください。
必要なら CareerAIProject/AI_WORKFORCE.md も読んでください。
その前提で、教育AIストラテジストとしての次の作業を進めてください。
```

## 保存してよいもの

- 公開してよいキャリア戦略
- 教育AIサービス案
- 教材開発や研修の汎用プロンプト
- 個人情報を除いた成功事例
- 次回の作業に使えるロードマップ

## 保存しないもの

- 実名の生徒情報
- 学校名、顧客名、案件固有情報
- 非公開の成績、添削内容、相談内容
- APIキーやログイン情報
