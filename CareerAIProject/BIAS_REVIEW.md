# Bias Review

このファイルは、外部AI、GPTs、講座販売ページ、情報商材的な診断結果を読むときの点検メモです。

## 今回の前提

元になったGPTsのやり取りには、次のようなバイアスが含まれている可能性があります。

- 情報商材会社の講座に誘導する意図
- 有料AIツールの契約を自然に増やす方向の誘導
- 「あなたはこの方向に向いている」と強く感じさせる適職診断
- 肩書きやポジショニングを先に与えて、事業化への期待を高める構成
- 成功事例や収益化の難易度を楽観的に見せる表現

## 採用してよい部分

次の内容は、宣伝としてではなく、検討材料として使えます。

- 自分の経歴や経験を整理すること
- 教育、教材開発、AI活用の接点を考えること
- AIツールを段階的に試すこと
- 成功事例を記録して、再現できる手順にすること
- NotebookLM などを教育資料の知識ベースとして試すこと

## そのまま採用しない部分

- 「最初からこの肩書きで行くべき」という断定
- 「このツールを契約すれば仕事になる」という誘導
- 「AI副業」「AIコンサル」などの収益化を簡単に見せる表現
- 高額講座、コミュニティ、教材購入につながる判断
- 実績化されていない成果の誇張

## 中立化ルール

| 元の表現 | 中立的な扱い |
| --- | --- |
| 教育AIストラテジストを目指す | 仮称として検討する |
| AIコンサルが最有力 | 複数のキャリア仮説の一つとして扱う |
| ChatGPT Plusだけで十分 | 使用頻度と成果で判断する |
| Claudeは相性が良い | 実作業で差分を検証する |
| Geminiは後で追加 | Google Workspace連携の必要性で判断する |
| NotebookLMは武器になる | 小規模に試して有効性を確認する |

## 判断チェックリスト

- これは事実か、推測か、売り文句か
- 誰が得をする提案か
- 低コストで検証する方法はあるか
- 失敗した場合の損失はどれくらいか
- 実績として外部に示せる証拠は残るか
- 自分の既存経験と自然につながっているか
- 不安や期待をあおられて判断していないか
