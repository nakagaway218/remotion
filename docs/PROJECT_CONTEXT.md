# Project Context

## Purpose

This repository is the user's main GitHub workspace for work shared across ChatGPT/Codex, and potentially Claude Code in the future. It contains multiple project areas, tools, notes, learning materials, and recovery or handoff documents.

The goal of this shared context is to make work portable between AI assistants without relying only on chat history.

## Current Repository Shape

This repository currently includes several top-level project folders, including but not limited to:

- `Mytools/` - local tools and launcher-related work.
- `Webarticle/` - article-writing support tooling and Antigravity handoff notes.
- `Scenariowriting/` - scenario-writing tooling and recovery notes.
- `CareerAIProject/` - career-related AI project materials.
- `ObsidianSecondBrain/` - Obsidian and knowledge-management materials.
- `Studymaterials/` - study materials.
- `Rikei_Kokkoritsu_Juken_Learner/` - recovered learner-related materials.
- `worklogs/` - chronological working notes from AI-assisted sessions.

The root `README.md` still appears to come from the original Remotion upstream project. Do not treat it as the only source of truth for the current workspace.

## Existing Shared Context

Before starting substantial work, read these files when they are relevant:

- `AGENTS.md` - repository-wide working rules for Codex-style agents.
- `CLAUDE.md` - lightweight Claude Code entry point.
- `AI_CONTEXT.md` - repository background and accumulated context.
- `DESIGN.md` - structure and design policy for the workspace.
- `SKILL.md` - repeatable project workflow notes.
- `worklogs/` - recent work history.
- `tasks/` - task-level handoff notes.

## Operating Assumptions

- User-facing explanations should usually be in Japanese.
- Existing files may contain work from the user, Codex, Claude Code, Antigravity, or another assistant.
- Uncommitted changes should be treated as valuable until confirmed otherwise.
- Prefer small, reversible edits that preserve the existing structure.
- If a task is interrupted, leave a Markdown note with the current state, remaining work, and next action.
